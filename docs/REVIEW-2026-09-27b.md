## 2. The seven high findings, and their fixes

- **CS2-01: approving a new catalogue version froze the mother bank.** The
  mother-line checks compared product row ids. Approving a fitted page retires
  the old row, so no later generation or new stock plant could register. The
  line key is now the product code, and mothers are moved onto the live page.
  Fixed in `ddd8641`.
- **DI2-01: CI's compose job was red.** The environment template shipped an
  empty capture token, which the compose check refuses. Since the deploy
  workflow refuses a red commit, nothing was deployable. Fixed in `8e14d3a`.
- **R2-FE-01: six manager roles could not open Approvals.** The handoff list
  lived in a module keyed to QA, QC and QP only. Approvals now sits in the
  Tasks module for every manager role. Fixed in `c232da1`.
- **R2-FE-02: the pesticide re-entry line and signature times printed UTC.**
  The first round's timestamp guard had exempted seven files owned by other
  workstreams. All seven were converted and the exemption list is now empty.
  Fixed in `0a08ebe` and `559f3ad`.
- **R2-FE-03: the production manager was hidden from waste, decon and
  biosecurity.** The backend already admitted the role for dry rooms. The
  screens now mirror that rule. Fixed in `b1b347e`.
- **INS2-01: out-of-grade CoQs were blocked from issuance.** The owner said
  "NO for now" twice. The rule is now a tracked follow-up that marks the CoQ
  as owing its formal OOS, not a gate. Fixed in `41a4e32` and `230707c`.
- **INS2-02: the handoff told the owner to delete a token a workflow needs.**
  A cloud variable and a GitHub secret share one name. The handoff now says
  which is which. Fixed in `ecab327`.

Four items were closed in the last commits of the round, after the
workstreams had handed back:

- **R2-FE-09: a handoff vanished once its notification was marked done.**
  The Approvals list was rebuilt from inbox notifications. A new route,
  `GET /handoffs/pending`, lists the proposals the caller may decide from the
  handoffs themselves, using the same rule the resolve route applies.
- **R2-FE-12: feed and IPM records carried no date.** A spray written up the
  next morning shifted the pre-harvest and re-entry windows by a day. Both
  forms now carry a day, and the IPM form a time, defaulting to the
  facility's now. Decision E-11 records that the future bound is client-side.
- **R2-FE-13: four loaders could show a stale answer.** An older response
  that arrived last overwrote the newer list. The cultivation, propagation,
  facility and irrigation loaders now carry the sequence guard the waste
  view already had.
- **INV-08 and INV-09: dead code and duplicated logic.** The unused imports,
  functions, constants, script locals and style classes are gone. The
  duplicated logic had already drifted into a real bug, described below.

**INV-09 was a live bug, not only duplication.** The mother bank kept its own
copy of the catalogue's "tested so far" queries. The catalogue's copy was
fixed in round 2 to derive Total Δ9-THC from its components. The mother
bank's copy still read stored total rows, which are refused on entry since
QC-10. Every mother therefore showed an empty certificate source. The mother
bank now calls the catalogue's function, and a test pins it. The same finding
unified three smaller copies:

- **CoQ derived totals.** The two CoQ paths gave different verdicts on one
  certificate. Both now refuse a legacy transcribed total and name the
  certificate. Decision B-18 records the choice.
- **The facility day.** Five modules carried their own helper. They now call
  the one in `worktime`.
- **The department family.** The auth module re-implemented the shared
  helper. It now calls it.
