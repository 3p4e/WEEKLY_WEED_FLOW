## 4. PRINCIPLE

Cannabinoids are extracted from plant material using organic solvent, diluted, and analyzed by reversed-phase HPLC. Separation is achieved on a C18 column with gradient elution. Detection is by UV absorbance at <span class="var">[220 nm]</span>. Quantification is performed against certified reference standards using external calibration.

**Total cannabinoid calculation** accounts for decarboxylation:
- Total THC = Δ9-THC + (THCA × <span class="var">[0.877]</span>)
- Total CBD = CBD + (CBDA × <span class="var">[0.877]</span>)

## 7. STANDARD PREPARATION

### 7.1 Stock Standard Solutions

**Individual Stock Standards (<span class="var">[1000 µg/mL]</span>):**

1. Allow reference standard vials to equilibrate to room temperature (<span class="var">[30 minutes]</span>)
2. Weigh accurately <span class="var">[10.0 mg]</span> of each reference standard
3. Transfer quantitatively to <span class="var">[10 mL]</span> volumetric flask
4. Dissolve and dilute to volume with methanol
5. Mix thoroughly
6. Transfer to labeled amber vial
7. Store at <span class="var">[-20°C]</span>
8. Stability: <span class="var">[6 months]</span>

### 7.2 Mixed Working Standard Solution

**Mixed Standard (<span class="var">[100 µg/mL each]</span>):**

1. Pipette <span class="var">[1.0 mL]</span> of each stock standard into <span class="var">[10 mL]</span> volumetric flask
2. Dilute to volume with methanol
3. Mix thoroughly
4. Store at <span class="var">[2-8°C]</span>
5. Stability: <span class="var">[1 month]</span>

### 7.3 Calibration Standards

Prepare from mixed working standard:

| Level | Concentration (µg/mL) | Dilution |
|-------|----------------------|----------|
| L1 | <span class="var">[1]</span> | <span class="var">[100 µL → 10 mL]</span> |

## 8. SAMPLE PREPARATION

### 8.1 Cannabis Flower

#### 8.1.1 Sample Homogenization

1. Grind sample using clean grinder until homogeneous powder
2. Pass through <span class="var">[1 mm]</span> sieve if needed
3. Mix thoroughly
4. Record sample appearance

#### 8.1.2 Extraction

1. Weigh accurately <span class="var">[100.0 ± 1.0 mg]</span> homogenized sample
2. Transfer to <span class="var">[15 mL]</span> centrifuge tube
3. Add <span class="var">[10.0 mL]</span> extraction solvent (methanol)
4. Cap securely
5. Vortex <span class="var">[30 seconds]</span>
6. Sonicate <span class="var">[15 minutes]</span> at room temperature
7. Vortex <span class="var">[30 seconds]</span>
8. Centrifuge at <span class="var">[3000 rpm for 10 minutes]</span>

#### 8.1.3 Dilution

1. Transfer <span class="var">[1.0 mL]</span> supernatant to <span class="var">[10 mL]</span> volumetric flask
2. Dilute to volume with methanol
3. Mix thoroughly
4. Filter through <span class="var">[0.22 µm PTFE]</span> into HPLC vial

**Final dilution factor:** <span class="var">[1000×]</span> (100 mg in 10 mL, then 1:10)

### 8.2 Quality Control Samples

#### 8.2.1 System Suitability Standard

- Use calibration level L4 (<span class="var">[25 µg/mL]</span>)
- Inject <span class="var">[5 times]</span> at start of sequence

#### 8.2.2 Quality Control Sample (QC)

- In-house reference material or spiked sample
- Prepare at known concentration
- Include in each analytical batch

#### 8.2.3 Blank

- Extraction solvent (methanol)
- Processed through dilution steps

## 10. CALCULATIONS

### 10.1 Calibration Curve

- Plot peak area (y) vs. concentration (x)
- Use linear regression
- Correlation coefficient (r²): <span class="var">[≥0.995]</span>

### 10.2 Sample Concentration

$$C_{sample} = \frac{(Area_{sample} - Intercept)}{Slope}$$

### 10.3 Content Calculation

$$Content (\%w/w) = \frac{C_{sample} \times V \times DF}{W \times 10000}$$

Where:
- C = Concentration from calibration (µg/mL)
- V = Final volume (mL)
- DF = Dilution factor
- W = Sample weight (mg)

### 10.4 Total Cannabinoid Calculation

$$Total\ THC\ (\%) = Δ9\text{-}THC\ (\%) + (THCA\ (\%) × 0.877)$$

$$Total\ CBD\ (\%) = CBD\ (\%) + (CBDA\ (\%) × 0.877)$$

The factor <span class="var">[0.877]</span> accounts for loss of CO₂ during decarboxylation (molecular weight correction).

## 12. TROUBLESHOOTING

| Problem | Possible Cause | Solution |
|---------|---------------|----------|
| Poor resolution | Column degradation | Replace column |
| Retention time drift | Mobile phase issue | Prepare fresh mobile phase |
| Peak tailing | Active sites on column | Wash column, adjust mobile phase pH |
| Low recovery | Incomplete extraction | Increase sonication time, verify solvent |
| High baseline noise | Contaminated mobile phase | Use fresh HPLC-grade solvents |
| Carryover | Insufficient wash | Increase wash volume, use stronger wash |
