## 1. Purpose

This Standard Operating Procedure establishes validated methods for the positive identification of cannabis and cannabis-derived materials to ensure the correct botanical origin, authenticity, and quality of all materials received and processed. The procedure encompasses macroscopic, microscopic, chemical, and molecular identification techniques in compliance with European Pharmacopoeia requirements and EU GMP standards.

---

## 2. Scope

This SOP applies to identity testing of:

- **Cannabis inflorescence** (dried flowers)
- **Cannabis herba** (dried aerial parts)
- **Cannabis leaf** material
- **Cannabis extracts** (oils, concentrates, tinctures)
- **Cannabis API** (Active Pharmaceutical Ingredients)
- **Incoming raw materials**
- **In-process materials**
- **Finished products**

### 2.1 Identity Testing Methods

| Method | Application | Regulatory Reference |
|--------|-------------|---------------------|
| **Macroscopic Examination** | Botanical identification | Ph. Eur. 2.8.3 |

## 6. Macroscopic Examination

### 6.1 Procedure

**Sample Preparation:**

1. **Examine** representative sample (<span class="var">[≥10 g]</span>)
2. **Spread** material on white background
3. **Use** magnifying glass (10×) for initial observation
4. **Document** with photography

**Examination Parameters:**

| Parameter | Expected Observation | Record |
|-----------|---------------------|--------|
| **Overall Appearance** | Dense flower clusters (inflorescence) | Description |
| **Color** | Green to purple-green with orange pistils | Color code |
| **Size** | Inflorescence <span class="var">[10-30 mm]</span> length typical | Measurement |
| **Texture** | Sticky, resinous | Description |
| **Odor** | Characteristic terpene profile | Description |
| **Foreign Matter** | Seeds, stems, other plant parts | % by weight |

### 6.2 Macroscopic Characteristics of Cannabis

**Inflorescence (Flower):**

| Feature | Description |
|---------|-------------|
| **Structure** | Compact clusters of female flowers with bracts and bracteoles |
| **Bracts** | Leaf-like structures <span class="var">[3-5 mm]</span> covered with glandular trichomes |
| **Pistils** | Two stigmatic surfaces per flower, orange to brown when mature |
| **Trichomes** | Visible as frosted/crystalline appearance |
| **Calyx** | Enclosed by bract, contains achene (seed) if pollinated |

**Leaf:**

| Feature | Description |
|---------|-------------|
| **Arrangement** | Palmately compound, opposite to alternate |
| **Leaflets** | <span class="var">[3-9]</span> per leaf, typically <span class="var">[5-7]</span> |
| **Shape** | Lanceolate with serrated margins |
| **Venation** | Pinnate |
| **Surface** | Glandular and non-glandular trichomes on both surfaces |

**Stem:**

| Feature | Description |
|---------|-------------|
| **Cross-section** | Quadrangular to rounded |
| **Surface** | Longitudinal grooves, pubescent |
| **Internal** | Hollow pith when mature |

### 6.3 Macroscopic Acceptance Criteria

| Criterion | Specification | Fail Criteria |
|-----------|--------------|---------------|
| **Botanical Features** | Consistent with *Cannabis sativa* | Not consistent |
| **Foreign Organic Matter** | <span class="var">[≤2%]</span> | >2% |
| **Foreign Inorganic Matter** | <span class="var">[≤0.5%]</span> | >0.5% |
| **Mold (Visible)** | Absent | Present |
| **Pest Damage (Visible)** | <span class="var">[≤5%]</span> of material | >5% |
| **Seeds (if flower)** | <span class="var">[≤3%]</span> | >3% |

### 6.4 Documentation

Complete **Macroscopic Examination Form (FM-QC-043)** including:
- Sample photographs
- All measurement data
- Comparison to reference specimen
- Pass/Fail determination
- Analyst signature and date

## 7. Microscopic Examination

### 7.1 Sample Preparation

**Powder Preparation:**

1. **Grind** sample to fine powder (<span class="var">[250 µm]</span>)
2. **Mount** small amount in appropriate medium

**Section Preparation:**

1. **Cut** thin transverse or longitudinal sections
2. **Clear** in chloral hydrate solution at <span class="var">[60°C]</span> for <span class="var">[15-30 minutes]</span>
3. **Mount** in dilute glycerin

**Surface Preparation:**

1. **Peel** epidermis with fine forceps
2. **Mount** directly in dilute glycerin

### 7.2 Diagnostic Microscopic Features

**Trichomes (Most Important Diagnostic Feature):**

| Trichome Type | Description | Location | Size |
|---------------|-------------|----------|------|
| **Capitate-Stalked Glandular** | Multicellular stalk, spherical head with secretory disk | Bracts, leaves | Head <span class="var">[70-100 µm]</span>, stalk <span class="var">[150-500 µm]</span> |
| **Capitate-Sessile Glandular** | No stalk, head sits on epidermis | Bracts, leaves | Head <span class="var">[25-50 µm]</span> |
| **Bulbous Glandular** | Smallest, bulb-shaped | Throughout | <span class="var">[15-30 µm]</span> |
| **Non-Glandular (Cystolithic)** | Unicellular, curved, with CaCO₃ cystolith at base | Leaves, stems | <span class="var">[200-400 µm]</span> |

**Leaf Epidermis:**

| Feature | Upper Surface | Lower Surface |
|---------|--------------|---------------|
| **Cells** | Irregular, sinuous walls | More sinuous |
| **Stomata** | Absent or rare | Anomocytic, abundant |
| **Trichomes** | Both types present | Both types, more glandular |
| **Cystoliths** | Visible in non-glandular hair base | Visible |

**Vascular Tissue:**

| Feature | Description |
|---------|-------------|
| **Xylem** | Spiral and annular vessels |
| **Phloem** | Present |
| **Fibers** | Bast fibers in stem, <span class="var">[15-40 µm]</span> diameter |
| **Pith** | Parenchymatous, may contain cluster crystals |

**Pollen (Male Flowers):**

| Feature | Description |
|---------|-------------|
| **Shape** | Spherical |
| **Size** | <span class="var">[25-30 µm]</span> diameter |
| **Pores** | Triporate |
| **Surface** | Microspinulose |

### 7.3 Staining Reactions

| Test | Reagent | Positive Result | Structure Identified |
|------|---------|-----------------|---------------------|
| **Lignin** | Phloroglucinol/HCl | Red-pink color | Xylem vessels, fibers |
| **Lipids/Resin** | Sudan III | Orange-red | Glandular trichome heads |
| **Starch** | Lugol's iodine | Blue-black | Parenchyma (rare in cannabis) |
| **Calcium Carbonate** | Dilute HCl | Effervescence | Cystoliths |
| **Mucilage** | Ruthenium red | Pink | Cell walls (rare) |

### 7.4 Microscopic Examination Procedure

1. **Prepare** slides as per 7.1
2. **Examine** at <span class="var">[100×]</span> for overview
3. **Examine** at <span class="var">[400×]</span> for trichome details
4. **Perform** staining reactions as needed
5. **Photograph** diagnostic features
6. **Compare** to reference slides

### 7.5 Microscopic Acceptance Criteria

| Criterion | Specification |
|-----------|--------------|
| **Capitate-Stalked Trichomes** | Present |
| **Capitate-Sessile Trichomes** | Present |
| **Non-Glandular Trichomes with Cystoliths** | Present |
| **Anomocytic Stomata** | Present on lower epidermis |
| **Xylem Vessels** | Spiral/annular present |
| **Overall Features** | Consistent with reference |

### 7.6 Documentation

Complete **Microscopic Examination Form (FM-QC-044)** including:
- Photomicrographs of diagnostic features
- Measurements of key structures
- Staining reaction results
- Comparison to reference
- Pass/Fail determination

## 8. Thin Layer Chromatography (TLC)

### 8.1 Cannabinoid TLC Fingerprint

**Sample Preparation:**

1. **Weigh** <span class="var">[1.0 g]</span> powdered material
2. **Extract** with <span class="var">[10 mL]</span> methanol
3. **Sonicate** <span class="var">[15 minutes]</span>
4. **Centrifuge** <span class="var">[5 minutes]</span> at <span class="var">[3000 rpm]</span>
5. **Use** supernatant for TLC

**Reference Solution:**

1. **Prepare** mixed cannabinoid standard:
   - THC: <span class="var">[1 mg/mL]</span>
   - CBD: <span class="var">[1 mg/mL]</span>
   - CBN: <span class="var">[0.5 mg/mL]</span>
   - In methanol

**Chromatographic Conditions:**

| Parameter | Specification |
|-----------|--------------|
| **Plate** | <span class="var">[Silica gel 60 F₂₅₄]</span> |
| **Application** | <span class="var">[5 µL]</span> as bands, <span class="var">[10 mm]</span> from bottom |
| **Mobile Phase** | <span class="var">[Petroleum ether:Diethyl ether (80:20)]</span> |
| **Development Distance** | <span class="var">[10 cm]</span> |
| **Chamber Saturation** | <span class="var">[30 minutes]</span> |
| **Detection** | UV 254 nm, UV 365 nm, Fast Blue B |

**Detection Procedure:**

1. **Dry** plate in air <span class="var">[5 minutes]</span>
2. **View** under UV 254 nm (quenching zones)
3. **View** under UV 365 nm (fluorescence)
4. **Spray** with Fast Blue B reagent
5. **Observe** color development immediately

**Expected Rf Values and Colors:**

| Compound | Rf | UV 254 | UV 365 | Fast Blue B |
|----------|-----|--------|--------|-------------|
| **THC** | <span class="var">[0.50-0.55]</span> | Quenching | Blue fluorescence | Orange-red |
| **CBD** | <span class="var">[0.35-0.40]</span> | Quenching | Weak fluorescence | Orange |
| **CBN** | <span class="var">[0.45-0.50]</span> | Quenching | Strong blue | Purple-red |
| **THCA** | <span class="var">[0.25-0.30]</span> | Quenching | Blue | Orange |
| **CBDA** | <span class="var">[0.15-0.20]</span> | Quenching | Blue | Orange |

### 8.2 TLC Acceptance Criteria

| Criterion | Specification |
|-----------|--------------|
| **Separation** | Cannabinoids clearly resolved |
| **Reference Match** | Sample bands match reference Rf ± <span class="var">[0.05]</span> |
| **Color Development** | Characteristic colors observed |
| **Profile Consistency** | Consistent with declared chemotype |
| **Foreign Substances** | No unexpected zones |

### 8.3 Chemotype Confirmation by TLC

| Chemotype | Expected TLC Pattern |
|-----------|---------------------|
| **Type I (THC-dominant)** | Strong THC zone, weak/absent CBD |
| **Type II (Balanced)** | Both THC and CBD zones visible |
| **Type III (CBD-dominant)** | Strong CBD zone, weak/absent THC |

## 10. FTIR Spectroscopy

### 10.1 Sample Preparation

**ATR Method (Preferred):**

1. **Clean** ATR crystal with isopropanol
2. **Place** small amount of sample on crystal
3. **Apply** pressure to ensure good contact
4. **Collect** spectrum

**KBr Pellet Method (Alternative):**

1. **Mix** <span class="var">[2 mg]</span> sample with <span class="var">[200 mg]</span> KBr
2. **Grind** to homogeneous powder
3. **Press** pellet at <span class="var">[10 tons]</span>
4. **Collect** spectrum

### 10.2 Spectral Collection Parameters

| Parameter | Setting |
|-----------|---------|
| **Spectral Range** | <span class="var">[4000-400 cm⁻¹]</span> |
| **Resolution** | <span class="var">[4 cm⁻¹]</span> |
| **Number of Scans** | <span class="var">[32]</span> |
| **Background** | Clean crystal/blank KBr |
| **Apodization** | Happ-Genzel |

### 10.3 Characteristic IR Bands for Cannabis

| Wavenumber (cm⁻¹) | Assignment | Intensity |
|-------------------|------------|-----------|
| <span class="var">[3400-3200]</span> | O-H stretch (phenolic, hydroxyl) | Broad |
| <span class="var">[2920-2850]</span> | C-H stretch (alkyl chains) | Strong |
| <span class="var">[1740-1700]</span> | C=O stretch (carboxylic acids, esters) | Medium |
| <span class="var">[1620-1580]</span> | C=C stretch (aromatic) | Medium |
| <span class="var">[1510-1450]</span> | Aromatic ring vibrations | Medium |
| <span class="var">[1380-1360]</span> | C-H bend (methyl) | Medium |
| <span class="var">[1260-1200]</span> | C-O stretch (phenolic) | Strong |
| <span class="var">[1150-1050]</span> | C-O stretch (ether) | Medium |
| <span class="var">[890-800]</span> | C-H out-of-plane (aromatic) | Weak |

### 10.4 Spectral Comparison

**Library Search:**

1. **Build** cannabis reference library from authenticated samples
2. **Include** different chemotypes and cultivars
3. **Search** sample spectrum against library
4. **Accept** if match factor <span class="var">[≥95%]</span>

**Manual Comparison:**

1. **Overlay** sample and reference spectra
2. **Verify** major peaks match within <span class="var">[±5 cm⁻¹]</span>
3. **Check** relative intensities similar
4. **Note** any significant differences

### 10.5 FTIR Acceptance Criteria

| Criterion | Specification |
|-----------|--------------|
| **Library Match** | <span class="var">[≥95%]</span> hit quality |
| **Peak Positions** | Within <span class="var">[±5 cm⁻¹]</span> of reference |
| **Spectral Profile** | Consistent with cannabis |
| **Contamination** | No unexpected bands |

## 11. Molecular Identification (DNA Barcoding)

### 11.1 Application

DNA barcoding is used when:
- Macroscopic/microscopic features are inconclusive
- Material is highly processed (extracts, powders)
- Species-level confirmation required
- Adulteration suspected

### 11.2 DNA Extraction

**Sample Preparation:**

1. **Weigh** <span class="var">[100 mg]</span> dried plant material
2. **Grind** in liquid nitrogen
3. **Use** commercial plant DNA extraction kit
4. **Follow** manufacturer's protocol

**Quality Assessment:**

| Parameter | Specification |
|-----------|--------------|
| **DNA Yield** | <span class="var">[≥10 ng/µL]</span> |
| **A260/A280 Ratio** | <span class="var">[1.8-2.0]</span> |
| **A260/A230 Ratio** | <span class="var">[≥2.0]</span> |
| **Integrity** | Visible on agarose gel |

### 11.3 PCR Amplification

**Target Regions:**

| Region | Primers | Amplicon Size | Application |
|--------|---------|---------------|-------------|
| **ITS2** (Internal Transcribed Spacer 2) | ITS2F/ITS2R | <span class="var">[~300 bp]</span> | Plant ID |
| **rbcL** (RuBisCO large subunit) | rbcLa-F/rbcLa-R | <span class="var">[~550 bp]</span> | Plant ID |
| **matK** (Maturase K) | matK-3F/matK-1R | <span class="var">[~850 bp]</span> | Plant ID |

**PCR Conditions:**

| Stage | Temperature | Time | Cycles |
|-------|-------------|------|--------|
| Initial Denaturation | <span class="var">[95°C]</span> | <span class="var">[5 min]</span> | 1 |
| Denaturation | <span class="var">[95°C]</span> | <span class="var">[30 sec]</span> | 35 |
| Annealing | <span class="var">[55°C]</span> | <span class="var">[30 sec]</span> | 35 |
| Extension | <span class="var">[72°C]</span> | <span class="var">[60 sec]</span> | 35 |
| Final Extension | <span class="var">[72°C]</span> | <span class="var">[10 min]</span> | 1 |
| Hold | <span class="var">[4°C]</span> | ∞ | - |

### 11.4 Sequencing and Analysis

1. **Purify** PCR products
2. **Submit** for Sanger sequencing
3. **Analyze** sequences using:
   - BLAST against GenBank/BOLD databases
   - Alignment with reference sequences
4. **Accept** identity if:
   - Sequence similarity <span class="var">[≥99%]</span> to *Cannabis sativa*
   - E-value <span class="var">[<1e⁻⁵⁰]</span>
   - Coverage <span class="var">[≥95%]</span>

### 11.5 DNA Barcoding Acceptance Criteria

| Criterion | Specification |
|-----------|--------------|
| **Sequence Quality** | Phred score <span class="var">[≥20]</span> for >90% of sequence |
| **BLAST Match** | Top hit: *Cannabis sativa* |
| **Sequence Identity** | <span class="var">[≥99%]</span> |
| **Query Coverage** | <span class="var">[≥95%]</span> |

## 14. Out-of-Specification Results

### 14.1 Identity Failure Criteria

| Test | Failure Definition |
|------|-------------------|
| **Macroscopic** | Features inconsistent with *Cannabis sativa* |
| **Microscopic** | Diagnostic features absent or inconsistent |
| **TLC** | Profile not matching cannabis |
| **HPLC** | Cannabinoid pattern inconsistent |
| **FTIR** | Spectrum not matching reference |
| **DNA** | Sequence not matching *Cannabis sativa* |

### 14.2 OOS Investigation

1. **Repeat** failed test on same sample
2. **If still failing**: Test alternate sample portion
3. **If still failing**: Perform additional confirmatory tests
4. **Document** all investigation steps

### 14.3 Actions for Failed Identity

| Outcome | Action |
|---------|--------|
| **Confirmed failure** | REJECT material |
| **Adulteration suspected** | Full investigation + supplier audit |
| **Contamination identified** | Assess extent, potential remediation |
| **Inconclusive** | Additional testing, expert consultation |
