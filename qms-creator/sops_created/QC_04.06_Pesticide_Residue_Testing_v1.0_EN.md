## 1. Purpose

This Standard Operating Procedure establishes comprehensive procedures for the detection and quantification of pesticide residues in cannabis and cannabis-derived materials using multi-residue screening methods. The procedure ensures compliance with European Union Maximum Residue Limits (MRLs) and specific cannabis regulatory requirements, providing verification that all products meet safety standards for human consumption.

---

## 2. Scope

This SOP applies to:

- **Cannabis flower** (dried inflorescence)
- **Cannabis trim** and leaf material
- **Cannabis extracts** (oils, concentrates, tinctures)
- **Intermediate products** during processing
- **Starting materials** (if applicable for incoming testing)
- **Finished pharmaceutical products**

### 2.1 Pesticide Categories Covered

| Category | Examples | Testing Method |
|----------|----------|----------------|
| **Organophosphates** | Chlorpyrifos, Malathion, Diazinon | GC-MS/MS, LC-MS/MS |
| **Organochlorines** | DDT, Lindane, Endosulfan | GC-MS/MS |
| **Pyrethroids** | Permethrin, Bifenthrin, Cypermethrin | GC-MS/MS, LC-MS/MS |
| **Carbamates** | Carbaryl, Carbofuran, Methomyl | LC-MS/MS |
| **Neonicotinoids** | Imidacloprid, Acetamiprid, Thiamethoxam | LC-MS/MS |
| **Fungicides** | Myclobutanil, Propiconazole, Imazalil | LC-MS/MS |
| **Growth Regulators** | Paclobutrazol, Daminozide | LC-MS/MS |
| **Herbicides** | Glyphosate, Paraquat | LC-MS/MS (derivatization) |
| **Acaricides** | Abamectin, Spiromesifen | LC-MS/MS |

## 3. Responsibilities

### 3.1 QC Analyst

- Perform sample extraction and preparation
- Operate LC-MS/MS and GC-MS/MS instruments
- Process data and identify/quantify pesticides
- Document all procedures and results
- Report Out-of-Specification (OOS) results immediately

### 3.2 QC Supervisor

- Review and approve analytical data
- Ensure method validation maintenance
- Oversee instrument qualification and maintenance
- Investigate OOS results
- Approve batch release decisions

### 3.3 QC Manager (<span class="var">[QC_MANAGER_NAME]</span>)

- Maintain method validation status
- Approve method changes and updates
- Review regulatory updates for pesticide limits
- Manage proficiency testing participation
- Report to Quality Assurance on compliance status

### 3.4 Quality Assurance

- Final review and batch disposition
- Trend analysis of pesticide data
- Regulatory reporting as required
- Audit of testing procedures

## 6. Sample Preparation Procedure

### 6.1 Sample Receipt and Storage

1. **Receive sample** with completed chain of custody form (FM-QC-025)
2. **Verify** sample identification matches documentation
3. **Record** sample condition upon receipt
4. **Store** samples at <span class="var">[-20°C]</span> until analysis
5. **Maximum holding time**: <span class="var">[30 days]</span> from receipt

### 6.2 Sample Homogenization

**For dried flower:**

1. **Grind** sample using laboratory mill with stainless steel blades
2. **Grind time**: <span class="var">[30 seconds]</span> at <span class="var">[15,000 rpm]</span>
3. **Target particle size**: <span class="var">[<1 mm]</span>
4. **Clean** grinder between samples with:
   - Brush to remove residue
   - Wipe with acetonitrile-soaked lint-free wipe
   - Grind blank matrix verification sample
5. **Store** homogenized sample in amber glass container at <span class="var">[-20°C]</span>

**For extracts/oils:**

1. **Warm** viscous samples to <span class="var">[40°C]</span> if needed
2. **Mix** thoroughly by vortexing <span class="var">[1 minute]</span>
3. **No grinding required** - sample directly

### 6.3 QuEChERS Extraction Procedure

**Step 1: Weigh Sample**

| Matrix | Sample Weight | Water Addition |
|--------|--------------|----------------|
| Dried flower | <span class="var">[2.0 g ± 0.1 g]</span> | <span class="var">[10 mL]</span> |
| Fresh plant | <span class="var">[10.0 g ± 0.5 g]</span> | None |
| Extracts/oils | <span class="var">[1.0 g ± 0.05 g]</span> | <span class="var">[5 mL]</span> |

**Step 2: Hydration (dried samples)**

1. Add ultrapure water to <span class="var">[50 mL]</span> centrifuge tube
2. Vortex <span class="var">[30 seconds]</span>
3. Let stand <span class="var">[15 minutes]</span> for hydration

**Step 3: Internal Standard Addition**

1. Add <span class="var">[100 µL]</span> internal standard working solution (<span class="var">[1 µg/mL]</span> each)
2. Vortex briefly to mix

**Step 4: Acetonitrile Extraction**

1. Add <span class="var">[15 mL]</span> acetonitrile (1% acetic acid)
2. Shake vigorously by hand <span class="var">[1 minute]</span>
3. Add QuEChERS extraction salt packet:
   - <span class="var">[6 g]</span> MgSO₄ (anhydrous)
   - <span class="var">[1.5 g]</span> NaCl
4. Shake immediately and vigorously <span class="var">[1 minute]</span>
5. Centrifuge at <span class="var">[4000 rpm]</span> for <span class="var">[5 minutes]</span>

**Step 5: Dispersive SPE Cleanup**

1. Transfer <span class="var">[8 mL]</span> supernatant to dispersive SPE tube containing:
   - <span class="var">[400 mg]</span> PSA
   - <span class="var">[400 mg]</span> C18
   - <span class="var">[400 mg]</span> GCB (for pigment removal)
   - <span class="var">[1200 mg]</span> MgSO₄
2. Vortex <span class="var">[30 seconds]</span>
3. Centrifuge at <span class="var">[4000 rpm]</span> for <span class="var">[5 minutes]</span>

**Step 6: Final Extract Preparation**

For LC-MS/MS:
1. Transfer <span class="var">[1 mL]</span> supernatant to autosampler vial
2. Add <span class="var">[1 mL]</span> ultrapure water
3. Vortex briefly
4. Filter through <span class="var">[0.22 µm]</span> PTFE if needed

For GC-MS/MS:
1. Transfer <span class="var">[4 mL]</span> supernatant to glass tube
2. Evaporate to <span class="var">[0.5 mL]</span> under nitrogen at <span class="var">[40°C]</span>
3. Transfer to autosampler vial

## 8. Calibration and Quality Control

### 8.1 Calibration Standards

**Standard Preparation:**

1. **Stock Solutions** (<span class="var">[1000 µg/mL]</span>):
   - Prepare from certified reference materials
   - Dissolve in acetonitrile
   - Store at <span class="var">[-20°C]</span> for <span class="var">[≤1 year]</span>

2. **Intermediate Working Solutions** (<span class="var">[10 µg/mL]</span>):
   - Dilute stock in acetonitrile
   - Store at <span class="var">[-20°C]</span> for <span class="var">[≤6 months]</span>

3. **Calibration Working Solutions**:
   - Prepare matrix-matched standards in blank cannabis extract
   - Concentration levels:

| Level | Concentration (µg/kg) |
|-------|----------------------|
| Cal 1 | <span class="var">[5]</span> (LOQ level) |
| Cal 2 | <span class="var">[10]</span> |
| Cal 3 | <span class="var">[25]</span> |
| Cal 4 | <span class="var">[50]</span> |
| Cal 5 | <span class="var">[100]</span> |
| Cal 6 | <span class="var">[250]</span> |
| Cal 7 | <span class="var">[500]</span> |
| Cal 8 | <span class="var">[1000]</span> |

### 8.2 Calibration Acceptance Criteria

| Criterion | Specification |
|-----------|--------------|
| **Correlation Coefficient (r²)** | <span class="var">[≥0.99]</span> |
| **Calibration Type** | Linear or quadratic (1/x weighted) |
| **Back-calculated Accuracy** | <span class="var">[±20%]</span> at LOQ, <span class="var">[±15%]</span> at other levels |
| **Residual Distribution** | Random, no systematic bias |
| **Internal Standard Response** | <span class="var">[±30%]</span> of mean |

### 8.3 Analytical Batch Composition

Each analytical batch shall include:

| QC Element | Frequency | Acceptance |
|------------|-----------|------------|
| **Reagent Blank** | 1 per batch | No interference |
| **Matrix Blank** | 1 per batch | No target analytes > LOQ |
| **Low QC** (LOQ level) | 1 per 10 samples | <span class="var">[±25%]</span> of nominal |
| **Mid QC** | 1 per 10 samples | <span class="var">[±20%]</span> of nominal |
| **High QC** | 1 per 10 samples | <span class="var">[±20%]</span> of nominal |
| **Duplicate Sample** | 1 per 10 samples | RPD <span class="var">[≤25%]</span> |
| **Matrix Spike** | 1 per 20 samples | Recovery <span class="var">[70-120%]</span> |
| **Calibration Verification** | Every 10 samples | <span class="var">[±20%]</span> of nominal |

### 8.4 System Suitability

**Before each analytical batch, verify:**

| Parameter | Specification | Action if Fail |
|-----------|--------------|----------------|
| **Retention Time** | <span class="var">[±0.2 min]</span> from reference | Re-equilibrate column |
| **Peak Symmetry** | Tailing factor <span class="var">[≤2.0]</span> | Check column/inlet |
| **Signal/Noise** | <span class="var">[≥10:1]</span> at LOQ | Troubleshoot system |
| **IS Response** | <span class="var">[±30%]</span> of expected | Check injection/source |
| **Ion Ratio** | <span class="var">[±30%]</span> of reference | Verify identification |

| **Retention Time** | <span class="var">[±0.1 min]</span> from calibration standard |
| **Qualifier Ion Ratio** | <span class="var">[±30%]</span> of calibration standard |
| **Signal/Noise** | <span class="var">[≥3:1]</span> for identification |
| **Two MRM Transitions** | Both must be present |

### 9.2 Quantification Procedure

1. **Integrate peaks** using vendor software
2. **Calculate concentration** using internal standard method:

$$Concentration_{sample} = \frac{(Response_{analyte}/Response_{IS})_{sample} × Concentration_{IS} × Volume_{final}}{(Response_{analyte}/Response_{IS})_{standard} × Weight_{sample}}$$

3. **Apply dilution factors** if applicable
4. **Report results** in µg/kg (ppb)

### 9.3 Reporting

**Result Categories:**

| Result | Interpretation | Report Format |
|--------|---------------|---------------|
| **ND** | Not Detected (< LOD) | "Not Detected (<LOD)" |
| **< LOQ** | Detected but below quantification limit | "Detected, < LOQ" |
| **Quantified** | Above LOQ, below action limit | Numeric value ± uncertainty |
| **FAIL** | Above action limit | Numeric value, flagged |

**Report shall include:**

- Sample identification and description
- Date of analysis
- Method reference
- All detected pesticides with concentrations
- Applicable action limits
- Pass/Fail determination
- Measurement uncertainty at detection level
- Analyst signature and date

### 9.4 Measurement Uncertainty

**Expanded uncertainty (U) at 95% confidence:**

| Concentration Range | Expanded Uncertainty |
|--------------------|---------------------|
| LOQ to 2× LOQ | <span class="var">[±40%]</span> |
| 2× LOQ to 10× LOQ | <span class="var">[±30%]</span> |
| > 10× LOQ | <span class="var">[±25%]</span> |

## 10. Out-of-Specification Results

### 10.1 OOS Investigation Procedure

**Phase 1 - Laboratory Investigation:**

1. **Verify data processing** - check integration, IS response, calibration
2. **Check chromatography** - retention time, peak shape, interferences
3. **Review sample preparation** - dilutions, weights, calculations
4. **Confirm instrument performance** - QC samples, system suitability

**Phase 2 - Reanalysis (if Phase 1 inconclusive):**

1. Re-extract from retained sample portion
2. Analyze with fresh calibration curve
3. Include additional QC samples

**Phase 3 - Re-sampling (if Phase 2 confirms OOS):**

1. Request new representative sample
2. Full analysis with enhanced QC

### 10.2 OOS Documentation

Complete Pesticide OOS Investigation Form (FM-QC-026) including:
- Original and retest results
- Root cause analysis
- Corrective actions
- Impact assessment

### 10.3 OOS Notification

| Pesticide Category | Notification Requirement |
|-------------------|-------------------------|
| Category 1 (prohibited) | Immediate verbal notification to QA |
| Category 2 (above limit) | Same-day written notification |
| Unexpected detection | Within 24 hours |
