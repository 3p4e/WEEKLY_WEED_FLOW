## 1. PURPOSE

1.1 This Standard Operating Procedure (SOP) establishes the requirements for the management, maintenance, and preservation of mother plants (stock plants) used as the genetic source for all propagation activities at <span class="var">[FACILITY_NAME]</span>.

1.2 The procedure ensures:
- Genetic integrity and identity of cultivar stock
- Consistent quality of starting material for propagation
- Traceability from mother plant to final product
- Compliance with EU GMP and GACP requirements
- Prevention of contamination and disease transmission

---

## 2. SCOPE

2.1 This SOP applies to:
- All mother plant cultivation activities
- Genetic library management
- Mother plant selection and qualification
- Maintenance and care of established mother plants
- Health monitoring and disease prevention
- Retirement and replacement procedures

2.2 This SOP does **not** cover:
- Propagation/cloning procedures (see <span class="var">[PRO_01.02]</span>)
- Seed germination (see <span class="var">[PRO_01.03]</span>)
- Vegetative growth of production plants (see <span class="var">[PRO_01.04]</span>)

## 4. DEFINITIONS

| Term | Definition |
|------|------------|
| **Mother Plant** | A mature, verified, and qualified stock plant maintained in the vegetative state for the purpose of providing cuttings (clones) for propagation |
| **Cultivar** | A plant variety that has been produced through selective breeding and is genetically distinct with identifiable characteristics |
| **Genetic Identity** | The verified genetic profile that confirms a plant belongs to a specific cultivar |
| **Stock Plant Number** | Unique identifier assigned to each individual mother plant |
| **Generation** | The number of propagation cycles from the original verified stock |
| **Vegetative State** | Growth phase where plants produce leaves and stems but not flowers, maintained by photoperiod control |
| **Meristem** | Actively growing plant tissue from which cuttings are taken |
| **Phenotype** | Observable physical characteristics of a plant determined by genetics and environment |

## 8. PROCEDURE

### 8.1 Mother Plant Selection and Qualification

#### 8.1.1 New Cultivar Introduction

1. **Source Verification**
   - Obtain documentation of genetic identity from source
   - Record source information: <span class="var">[Supplier, date, lot number]</span>
   - Quarantine new material in designated area for <span class="var">[minimum 14 days]</span>

2. **Quarantine Inspection**
   - Inspect daily for signs of pests or disease
   - Document observations in Quarantine Log <span class="var">[FM-CULT-001]</span>
   - Any abnormality → initiate deviation report

3. **Genetic Verification**
   - Submit sample to QC for genetic identity testing per <span class="var">[QC_04.15]</span>
   - Compare results against reference profile (if available)
   - Results must confirm cultivar identity before release

4. **Phenotype Evaluation**
   - Grow through at least <span class="var">[one full vegetative cycle (4-6 weeks)]</span>
   - Evaluate against cultivar specifications:
     - Leaf morphology
     - Growth pattern
     - Node spacing
     - Color characteristics
   - Document in Cultivar Evaluation Form <span class="var">[FM-CULT-002]</span>

5. **Health Screening**
   - Test for common pathogens: <span class="var">[Pythium, Fusarium, powdery mildew, HpLVd]</span>
   - Negative results required before qualification
   - Positive results → reject or quarantine for treatment evaluation

6. **Qualification Approval**
   - Complete Mother Plant Qualification Form <span class="var">[FM-CULT-003]</span>
   - Obtain approval from:
     - Cultivation Manager (signature required)
     - Quality Assurance (signature required)
   - Assign Stock Plant Number upon approval

#### 8.1.2 Stock Plant Numbering System

Format: <span class="var">[CV-XXX-YY-###]</span>

| Component | Meaning | Example |
|-----------|---------|---------|
| CV | Cultivar code (3 letters) | <span class="var">[OGK]</span> |
| XXX | Generation number | <span class="var">[001]</span> |
| YY | Year established | <span class="var">[24]</span> |
| ### | Sequential number | <span class="var">[001]</span> |

**Example:** <span class="var">[OGK-001-24-005]</span> = OG Kush, Generation 1, established 2024, fifth plant

### 8.2 Mother Plant Establishment

#### 8.2.1 Container Preparation

1. Select appropriate container: <span class="var">[15-25 L food-grade]</span>
2. Clean and sanitize container per <span class="var">[PRO_05.01]</span>
3. Prepare drainage layer:
   - Add <span class="var">[2-3 cm]</span> expanded clay pebbles at bottom
4. Fill with growing medium:
   - Pre-moistened to <span class="var">[60-70% water holding capacity]</span>
   - Leave <span class="var">[3-5 cm]</span> from top for watering
5. Label container with:
   - Stock Plant Number
   - Cultivar name
   - Establishment date
   - QR code (if applicable)

#### 8.2.2 Plant Installation

1. Select healthy, qualified clone from propagation
2. Create hole in medium to accommodate root ball
3. Remove clone from propagation container carefully
4. Place in prepared container at original soil depth
5. Gently firm medium around base
6. Initial irrigation:
   - pH adjusted water: <span class="var">[5.8-6.0]</span>
   - Low EC: <span class="var">[0.6-0.8 mS/cm]</span>
   - Volume: <span class="var">[sufficient for 10% runoff]</span>
7. Record establishment in Mother Plant Log <span class="var">[FM-CULT-004]</span>

### 8.3 Daily Care and Maintenance

#### 8.3.1 Daily Inspection Checklist

Perform **every day** at start of shift:

| Check Point | Action | Record |
|-------------|--------|--------|
| Environmental parameters | Verify within range | Log readings |
| Plant health visual | Inspect each plant | Note abnormalities |
| Pest/disease signs | Examine leaves, stems, medium | Report immediately |
| Irrigation system | Check for blockages, leaks | Confirm operation |
| Lighting function | Verify all lights operational | Report failures |
| Air circulation | Confirm fan operation | Check airflow |

Document in Daily Mother Room Checklist <span class="var">[FM-CULT-005]</span>

#### 8.3.2 Irrigation and Nutrition

**Standard Irrigation Protocol:**

1. Check medium moisture before irrigation
   - Insert finger <span class="var">[2-3 cm]</span> into medium
   - Irrigate when top layer is dry but lower remains moist

2. Prepare nutrient solution:
   - Fill reservoir with purified water
   - Add nutrients per schedule:
   
   | Week | Nutrient A (mL/L) | Nutrient B (mL/L) | Target EC |
   |------|-------------------|-------------------|-----------|
   | Vegetative | <span class="var">[2.0]</span> | <span class="var">[1.0]</span> | <span class="var">[1.2-1.4]</span> |
   | Post-harvest | <span class="var">[2.5]</span> | <span class="var">[1.2]</span> | <span class="var">[1.4-1.6]</span> |
   | Recovery | <span class="var">[1.5]</span> | <span class="var">[0.8]</span> | <span class="var">[1.0-1.2]</span> |

3. Adjust pH:
   - Target: <span class="var">[5.8]</span>
   - Use phosphoric acid to lower / potassium hydroxide to raise
   - Never adjust more than <span class="var">[0.5 pH units]</span> at once

4. Record in Irrigation Log <span class="var">[FM-CULT-006]</span>:
   - Time of irrigation
   - Volume applied
   - pH and EC of solution
   - Runoff pH and EC
   - Any observations

#### 8.3.3 Pruning and Training

**Objectives:**
- Maintain plant structure for optimal cutting production
- Promote bushy growth with multiple branches
- Remove dead or diseased material
- Control plant height

**Pruning Procedure:**

1. Sterilize tools before and between each plant:
   - Dip in <span class="var">[70% isopropyl alcohol]</span> for <span class="var">[30 seconds]</span>
   - Allow to dry or flame-sterilize

2. Topping (apical meristem removal):
   - Perform when plant has <span class="var">[6-8 nodes]</span>
   - Cut cleanly above <span class="var">[4th-5th node]</span>
   - This promotes lateral branch development

3. Lollipopping (lower growth removal):
   - Remove lower <span class="var">[1/3 of growth]</span> to improve airflow
   - Perform every <span class="var">[2-3 weeks]</span> as needed

4. Selective pruning:
   - Remove yellowing or damaged leaves
   - Thin dense areas to allow light penetration
   - Remove any flowering (pre-flower) sites immediately

5. Document pruning activities in Mother Plant Care Log <span class="var">[FM-CULT-007]</span>

**Training Techniques:**

| Technique | Purpose | Frequency |
|-----------|---------|-----------|
| Low Stress Training (LST) | Horizontal growth promotion | Ongoing |
| Super cropping | Branch multiplication | As needed |
| Trellising | Structural support | At establishment |

### 8.4 Cutting Harvest (Clone Donation)

#### 8.4.1 Pre-Harvest Assessment

Before taking cuttings, verify:

| Criterion | Requirement |
|-----------|-------------|
| Plant health status | No visible pests, disease, or deficiency |
| Days since last harvest | Minimum <span class="var">[10-14 days]</span> recovery |
| Growth stage | Active vegetative growth |
| Node availability | Sufficient cutting sites available |
| Environmental conditions | Within specification for past <span class="var">[48 hours]</span> |

#### 8.4.2 Cutting Selection

Select cuttings with:
- <span class="var">[3-4 nodes]</span> minimum
- <span class="var">[10-15 cm]</span> length
- Healthy, turgid stems
- No signs of stress or damage
- Semi-hardwood consistency (not too soft or woody)

#### 8.4.3 Cutting Harvest Procedure

1. Water mother plant <span class="var">[2-4 hours]</span> before harvest
2. Prepare sterile cutting station:
   - Clean work surface
   - Sterilized cutting tools
   - Rooting hormone prepared
   - Labeled propagation containers ready
3. Make cut at <span class="var">[45° angle]</span> just below a node
4. Immediately place stem in water or rooting solution
5. Remove lower leaves, leaving <span class="var">[2-3 sets]</span> at top
6. Transfer to propagation per <span class="var">[PRO_01.02]</span>
7. Record in Cutting Harvest Log <span class="var">[FM-CULT-008]</span>:
   - Mother Plant ID
   - Number of cuttings taken
   - Date and time
   - Operator initials
   - Propagation batch assignment

#### 8.4.4 Post-Harvest Mother Plant Care

1. Inspect plant for any damage from harvest
2. Apply dilute nutrient solution: <span class="var">[EC 1.0-1.2 mS/cm]</span>
3. Allow recovery period before next harvest
4. Monitor for stress response
5. Document in Mother Plant Care Log

### 8.5 Health Monitoring and Disease Management

#### 8.5.1 Routine Health Monitoring

**Weekly Detailed Inspection:**

| Inspection Point | What to Check | Action if Abnormal |
|------------------|---------------|-------------------|
| Leaf color | Uniform green, no yellowing/browning | Identify deficiency/toxicity |
| Leaf texture | Turgid, no wilting or curling | Check irrigation/environment |
| Stem health | Firm, appropriate color | Check for rot/disease |
| Root inspection (if visible) | White, healthy appearance | Check for root disease |
| Pest presence | Undersides of leaves, nodes | Initiate IPM response |
| Growth rate | Consistent with expectations | Evaluate conditions |

Record in Weekly Health Assessment Form <span class="var">[FM-CULT-009]</span>

#### 8.5.2 Common Issues and Responses

| Issue | Indicators | Immediate Action |
|-------|------------|------------------|
| Nutrient deficiency | Yellowing, spots, discoloration | Adjust nutrition, investigate cause |
| Nutrient toxicity | Tip burn, claw leaves | Flush, reduce EC |
| Overwatering | Drooping, yellowing, root rot | Reduce frequency, check drainage |
| Underwatering | Wilting, dry medium | Increase frequency, check system |
| Pest infestation | Visible insects, damage patterns | Isolate, initiate IPM per <span class="var">[PRO_01.06]</span> |
| Disease symptoms | Spots, mold, unusual growth | Isolate, notify supervisor, sample for testing |
| Environmental stress | Various symptoms | Investigate environmental excursions |

#### 8.5.3 Quarantine Procedure

If disease or significant pest infestation is suspected:

1. **Immediately** isolate affected plant(s)
2. Move to quarantine area
3. Notify Mother Room Supervisor
4. Initiate Deviation Report if quality impact
5. Do NOT take cuttings from affected plants
6. Assess adjacent plants for spread
7. Implement enhanced monitoring
8. Document all actions

### 8.6 Mother Plant Retirement and Replacement

#### 8.6.1 Retirement Criteria

Mother plants should be retired when:

| Criterion | Threshold |
|-----------|-----------|
| Age | ><span class="var">[12-18 months]</span> from establishment |
| Generation | ><span class="var">[Generation 5]</span> from original |
| Health decline | Persistent issues despite intervention |
| Genetic drift concern | Observable phenotype changes |
| Production decline | Reduced cutting quality or quantity |
| Disease status | Confirmed positive for untreatable pathogen |

#### 8.6.2 Retirement Procedure

1. Complete Mother Plant Retirement Form <span class="var">[FM-CULT-010]</span>
2. Obtain approval from Cultivation Manager
3. If due to disease/contamination:
   - Handle as controlled substance waste
   - Dispose per <span class="var">[PRO_06.03]</span> Waste Management
4. If healthy retirement:
   - May be used for final cutting harvest
   - Then dispose per waste procedures
5. Update Genetic Library Register <span class="var">[FM-CULT-011]</span>
6. Archive all records for plant

#### 8.6.3 Replacement Planning

1. Monitor mother plant population against demand
2. Maintain succession plan:
   - Identify replacement candidates
   - Qualify replacements before retiring originals
3. Ensure minimum <span class="var">[2 mother plants]</span> per cultivar at all times
4. Replacement cuttings should be taken at <span class="var">[Generation N-1]</span>

### 8.7 Genetic Library Management

#### 8.7.1 Library Structure

Maintain records of:
- All cultivars authorized for production
- Genetic profiles/certificates of analysis
- Phenotype specifications
- Mother plant inventory per cultivar
- Historical performance data

#### 8.7.2 Genetic Verification Schedule

| Trigger | Testing Required |

| Annual verification | Identity confirmation per <span class="var">[QC_04.15]</span> |

## 11. DEVIATIONS

### 11.1 Common Deviations

| Deviation Type | Initial Response | Escalation |
|----------------|------------------|------------|
| Environmental excursion | Document, assess impact | If >Action Limit or >24 hours |
| Equipment failure | Backup system, emergency response | If prolonged or quality impact |
| Pest/disease detection | Isolate, initiate IPM | If spread or significant |
| Missed maintenance | Complete ASAP, document reason | If impacts plant health |
| Irrigation failure | Manual irrigation, repair | If >4 hours or impacts plants |

### 11.2 Deviation Reporting

1. Complete initial event documentation
2. Assess impact on:
   - Affected mother plants
   - Cuttings taken during period
   - Product quality/traceability
3. Complete Deviation Report per <span class="var">[QA_00.05]</span>
4. Implement corrective actions
5. Prevent recurrence through CAPA if systemic
