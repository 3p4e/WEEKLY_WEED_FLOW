## 1. PURPOSE

This SOP establishes the Integrated Pest Management (IPM) program for prevention, monitoring, identification, and control of pests and diseases in cannabis cultivation at <span class="var">[FACILITY_NAME]</span>, ensuring product safety and compliance with EU GMP and pesticide regulations.

---

## 2. SCOPE

Applies to:
- Preventive measures and facility design controls
- Pest and disease monitoring programs
- Identification and threshold determination
- Control measures (biological, physical, chemical)
- Documentation and reporting

---

## 3. IPM HIERARCHY

The IPM program follows this hierarchy of intervention:

| Priority | Method | Description |
|----------|--------|-------------|
| 1 | Prevention | Facility design, hygiene, environmental controls |
| 2 | Cultural Controls | Plant health, proper spacing, sanitation |
| 3 | Monitoring | Scouting, traps, early detection |
| 4 | Biological Controls | Beneficial insects, microbial agents |
| 5 | Physical/Mechanical | Removal, barriers, environmental adjustment |
| 6 | Chemical Controls | Last resort - approved products only |

| Area | Frequency | Method |
|------|-----------|--------|

| Drying/curing | <span class="var">[Daily]</span> | Visual inspection |

### 5.2 Monitoring Tools

| Tool | Placement | Check Frequency |
|------|-----------|-----------------|
| Yellow sticky traps (flying insects) | <span class="var">[1 per 10 m² at canopy level]</span> | <span class="var">[2x weekly]</span> |
| Blue sticky traps (thrips) | <span class="var">[Near entry points]</span> | <span class="var">[2x weekly]</span> |
| Potato slices (fungus gnats) | <span class="var">[On growing medium surface]</span> | <span class="var">[Weekly as needed]</span> |
| Hand lens/microscope | <span class="var">[Scout kit]</span> | <span class="var">[Each scouting session]</span> |

### 5.3 Scouting Procedure

1. Start with cleanest areas, proceed to potentially contaminated
2. Inspect systematically:
   - Upper leaf surfaces
   - **Undersides of leaves** (critical)
   - Stems and nodes
   - Growing medium surface
   - New growth tips
3. Use hand lens (<span class="var">[10-20x]</span>) for detailed inspection
4. Record findings in IPM Monitoring Log <span class="var">[FM-IPM-001]</span>

## 6. PEST AND DISEASE IDENTIFICATION

### 6.1 Common Pests

#### 6.1.1 Spider Mites (Tetranychus urticae)

| Characteristic | Description |
|----------------|-------------|
| Identification | <span class="var">[Tiny (<0.5mm), yellow/green/red dots on leaf undersides]</span> |
| Damage | <span class="var">[Stippling, bronzing, webbing in severe cases]</span> |
| Conditions | <span class="var">[Hot (>27°C), dry (<50% RH)]</span> |
| Threshold | <span class="var">[>5 per leaf = action required]</span> |

#### 6.1.2 Fungus Gnats (Bradysia spp.)

| Characteristic | Description |
|----------------|-------------|
| Identification | <span class="var">[Small black flies near soil surface, white larvae in medium]</span> |
| Damage | <span class="var">[Larvae feed on roots, vector for pathogens]</span> |
| Conditions | <span class="var">[Overwatered, wet growing medium]</span> |
| Threshold | <span class="var">[>10 adults per sticky trap/week = action]</span> |

#### 6.1.3 Thrips (Frankliniella occidentalis)

| Characteristic | Description |
|----------------|-------------|
| Identification | <span class="var">[Tiny elongated insects, silver/bronze streaking on leaves]</span> |
| Damage | <span class="var">[Rasping feeding, silvering, black fecal spots]</span> |
| Conditions | <span class="var">[Year-round, enter via plant material]</span> |
| Threshold | <span class="var">[>3 per leaf = action required]</span> |

#### 6.1.4 Aphids (Myzus persicae, others)

| Characteristic | Description |
|----------------|-------------|
| Identification | <span class="var">[Soft-bodied, pear-shaped, clustered on new growth]</span> |
| Damage | <span class="var">[Sap feeding, honeydew, sooty mold, virus vector]</span> |
| Conditions | <span class="var">[Year-round indoors]</span> |
| Threshold | <span class="var">[Any presence = action required]</span> |

#### 6.1.5 Whiteflies (Bemisia tabaci, Trialeurodes)

| Characteristic | Description |
|----------------|-------------|
| Identification | <span class="var">[Small white flying insects on leaf undersides]</span> |
| Damage | <span class="var">[Sap feeding, honeydew, sooty mold]</span> |
| Conditions | <span class="var">[Warm conditions]</span> |
| Threshold | <span class="var">[>5 per sticky trap/week = action]</span> |

### 6.2 Common Diseases

#### 6.2.1 Powdery Mildew (Golovinomyces cichoracearum)

| Characteristic | Description |
|----------------|-------------|
| Identification | <span class="var">[White powdery spots/coating on leaves]</span> |
| Damage | <span class="var">[Reduces photosynthesis, spreads rapidly, product contamination]</span> |
| Conditions | <span class="var">[High humidity (>65%), poor airflow, 20-27°C]</span> |
| Threshold | <span class="var">[ZERO TOLERANCE - any visible = action]</span> |

#### 6.2.2 Botrytis (Botrytis cinerea) - Bud Rot

| Characteristic | Description |
|----------------|-------------|
| Identification | <span class="var">[Gray-brown fuzzy mold on flowers, stem rot]</span> |
| Damage | <span class="var">[Destroys flowers, spreads rapidly, product contamination]</span> |
| Conditions | <span class="var">[High humidity (>60%), dense canopy, cool temps]</span> |
| Threshold | <span class="var">[ZERO TOLERANCE - any visible = immediate removal]</span> |

#### 6.2.3 Root Rot (Pythium, Fusarium)

| Characteristic | Description |
|----------------|-------------|
| Identification | <span class="var">[Brown/black roots, wilting despite wet medium, slime]</span> |
| Damage | <span class="var">[Root death, nutrient uptake failure, plant death]</span> |
| Conditions | <span class="var">[Overwatering, poor drainage, warm root zone]</span> |
| Threshold | <span class="var">[Any confirmed = immediate isolation]</span> |

#### 6.2.4 Hop Latent Viroid (HpLVd)

| Characteristic | Description |
|----------------|-------------|
| Identification | <span class="var">[Stunting, reduced vigor, malformed leaves, reduced yield/potency]</span> |
| Damage | <span class="var">[30-50% yield reduction, reduced cannabinoid content]</span> |
| Conditions | <span class="var">[Spreads via tools, hands, plant-to-plant contact]</span> |
| Threshold | <span class="var">[ZERO TOLERANCE - requires testing, cull positives]</span> |

|-------|-------------|------------------|-------|

| **Bacillus thuringiensis** | Caterpillars | <span class="var">[Per product label]</span> | <span class="var">[If applicable]</span> |

### 7.2 Physical/Mechanical Controls

| Method | Application |
|--------|-------------|
| Plant removal | Severely infested plants - cull |
| Leaf removal | Infested leaves - dispose properly |
| Water blast | Knock off soft-bodied pests |
| Vacuum | Remove visible adult insects |
| Temperature adjustment | Spider mites - lower temps and raise humidity |
| Sticky traps (mass trapping) | Increase density during outbreaks |

### 7.3 Approved Chemical Controls (Last Resort)

**CRITICAL:** Only EU-approved plant protection products permitted. Many common pesticides are NOT permitted on cannabis for pharmaceutical use.

| Product Type | Active Ingredient | Target | Restrictions |
|--------------|-------------------|--------|--------------|
| Insecticidal soap | <span class="var">[Potassium salts of fatty acids]</span> | Soft-bodied insects | <span class="var">[Not in flower week 5+]</span> |
| Neem oil | <span class="var">[Azadirachtin]</span> | Broad spectrum | <span class="var">[Not in flower]</span> |
| Pyrethrin | <span class="var">[Natural pyrethrins]</span> | Broad spectrum | <span class="var">[Not in flower week 4+]</span> |
| Sulfur (micronized) | <span class="var">[Eleite sulfur]</span> | Powdery mildew, mites | <span class="var">[Temperature restrictions, not in flower]</span> |
| Potassium bicarbonate | <span class="var">[KHCO₃]</span> | Powdery mildew | <span class="var">[Safe, limited efficacy]</span> |

**Application Requirements:**
1. Approval from QA Manager required
2. Document in Chemical Application Log <span class="var">[FM-IPM-002]</span>
3. Pre-Harvest Interval (PHI) must be observed
4. Post-harvest residue testing required
5. Operator PPE per product SDS

## 8. OUTBREAK RESPONSE PROTOCOL

### 8.1 Escalation Levels

| Level | Definition | Response |
|-------|------------|----------|
| **Level 1 - Detection** | <span class="var">[<Threshold, isolated]</span> | Monitor, cultural controls |
| **Level 2 - Action** | <span class="var">[At or above threshold]</span> | Biological + physical controls |
| **Level 3 - Outbreak** | <span class="var">[Spreading, multiple areas]</span> | Intensive intervention, isolation |
| **Level 4 - Critical** | <span class="var">[Widespread, production threat]</span> | Emergency response, potential crop loss |

### 8.2 Response Procedure

**Upon Detection:**

1. Document location, extent, pest/disease ID
2. Photograph for records
3. Notify IPM Coordinator/Cultivation Manager
4. Isolate affected area if possible
5. Initiate appropriate control measures
6. Increase monitoring frequency
7. Complete IPM Incident Report <span class="var">[FM-IPM-003]</span>

**For Level 3-4:**

1. Initiate deviation report per <span class="var">[QA_00.05]</span>
2. Consider room quarantine
3. Evaluate batch impact
4. Root cause investigation
5. CAPA implementation
