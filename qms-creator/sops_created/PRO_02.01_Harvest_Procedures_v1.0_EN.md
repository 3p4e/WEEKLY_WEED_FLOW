## 1. PURPOSE

This SOP establishes procedures for the controlled harvest of cannabis plants at <span class="var">[FACILITY_NAME]</span>, ensuring product quality, safety, and full traceability from cultivation through to post-harvest processing.

---

## 2. SCOPE

Applies to:
- Harvest readiness verification
- Pre-harvest preparation
- Cutting and handling of plants
- Initial processing (wet trimming if applicable)
- Transfer to drying
- Post-harvest batch documentation

### 4.2 Pre-Harvest Sampling

<span class="var">[48-72 hours]</span> before scheduled harvest:

1. QC takes representative samples per <span class="var">[QC_04.01]</span>
2. Samples submitted for:
   - Identity testing
   - Pre-harvest cannabinoid profile (optional)
   - Visual/organoleptic assessment
3. Results recorded in batch record

## 7. PROCEDURE

### 7.1 Pre-Harvest Preparation

**Day Before Harvest (D-1):**

1. Verify harvest schedule and authorization
2. Prepare Harvest Batch Record <span class="var">[FM-HARV-001]</span>
3. Confirm drying room readiness and capacity
4. Prepare and sanitize all equipment
5. Print labels with:
   - Batch number
   - Cultivar
   - Plant/row identification
   - Harvest date
6. Brief harvest team on procedures

**Harvest Day Morning:**

1. Final equipment and area inspection
2. Environmental conditions verification
3. Personnel gowning
4. Tool sterilization
5. Pre-harvest meeting with team

### 7.2 Harvest Execution

#### 7.2.1 Whole Plant Harvest (Preferred Method)

**Step 1: Plant Cutting**

1. Identify plant for harvest (match to label/record)
2. Record plant identification in batch record
3. Cut main stem at base:
   - <span class="var">[5-10 cm above growing medium]</span>
   - Clean, angled cut
   - Use sterilized cutting tool

4. Handle plant by stem, minimize flower contact
5. Visual inspection for:
   - Mold or bud rot
   - Pest presence
   - Any abnormalities
   
   **If issues detected:** Segregate plant, notify supervisor, document

**Step 2: Initial Processing (in Harvest Area)**

1. Remove large fan leaves:
   - Hand-strip or cut
   - Minimal handling of flowers
   - Dispose in designated waste

2. For whole-plant hanging:
   - Attach identification label to main stem
   - Hang inverted on drying line
   - Ensure adequate spacing (<span class="var">[15-20 cm between plants]</span>)

#### 7.2.2 Branch Harvest (Alternative)

If drying space or plant size requires:

1. Cut individual branches at main stem junctions
2. Label each branch with plant ID and branch number
3. Hang or rack individual branches
4. Maintain traceability to original plant

#### 7.2.3 Wet Trimming (If Used)

**Note:** Wet trimming removes sugar leaves before drying. Not all facilities use this method.

1. Perform immediately after harvest
2. Remove sugar leaves from flowers
3. Minimize flower handling
4. Collect trim separately (if retained)
5. Label trim with batch information
6. Proceed to drying without delay

### 7.3 Weighing and Documentation

#### 7.3.1 Wet Weight Recording

For each plant/batch unit:

1. Tare scale with empty container
2. Weigh harvested material (whole or per plant)
3. Record in Harvest Batch Record:
   - Plant ID
   - Wet weight (g)
   - Time of weighing
   - Operator initials

4. Calculate total batch wet weight:
   - Sum of all plants/units
   - Record batch total

#### 7.3.2 Yield Calculations

| Metric | Calculation | Target |
|--------|-------------|--------|
| Wet weight per plant | Individual measurement | <span class="var">[Cultivar-dependent]</span> |
| Wet weight per m² | Total ÷ grow area | <span class="var">[300-600 g/m² typical]</span> |
| Expected dry yield | Wet weight × <span class="var">[0.20-0.25]</span> | Estimate for planning |

### 7.4 Transfer to Drying

1. Complete harvest area activities
2. Verify all material is labeled and recorded
3. Transport to drying room:
   - Covered transport bins or direct hanging
   - Minimize time between harvest and drying setup
   - Maximum transit time: <span class="var">[30 minutes]</span>

4. Complete Transfer to Drying Form <span class="var">[FM-HARV-002]</span>:
   - Batch ID
   - Number of plants/units
   - Total wet weight
   - Drying room assignment
   - Receiving operator signature
   - Time of transfer

5. Initiate Drying Batch Record per <span class="var">[PRO_03.02]</span>

### 7.5 Post-Harvest Area Cleanup

After each harvest session:

1. Remove all plant material from harvest area
2. Sweep/vacuum floors
3. Clean and sanitize all work surfaces
4. Sanitize all tools
5. Dispose of waste per <span class="var">[PRO_06.03]</span>
6. Document cleaning on Room Cleaning Log <span class="var">[FM-CLEAN-001]</span>

## 8. QUALITY CONTROLS

### 8.1 In-Process Inspections

| Check | Frequency | Criteria | Action if Failed |
|-------|-----------|----------|------------------|
| Plant ID verification | Each plant | Matches batch record | Investigate discrepancy |
| Visual quality | Each plant | No mold, pests, severe damage | Segregate, document |
| Tool cleanliness | Between plants | No visible contamination | Re-sterilize |
| Glove integrity | Hourly | No tears, excessive soil | Change gloves |
| Environmental | <span class="var">[Every 2 hours]</span> | Within specifications | Adjust HVAC |

### 8.2 Batch Quality Assessment

Before transfer to drying:

| Assessment | Method | Acceptance |
|------------|--------|------------|
| Visual uniformity | Inspection | Consistent with cultivar |
| Aroma | Organoleptic | Characteristic, no off-odors |
| Moisture level | Touch assessment | Appropriate wet texture |
| Contamination | Visual | None detected |

## 9. DEVIATION HANDLING

### 9.1 Common Deviations

| Deviation | Initial Response | Escalation |
|-----------|------------------|------------|
| Mold detected on plant | Segregate, do NOT mix with batch | QA notification, deviation report |
| Pest damage discovered | Assess extent, segregate if significant | IPM assessment |
| Label/ID discrepancy | Stop harvest of affected unit, investigate | Cannot proceed without resolution |
| Equipment failure | Use backup, document | If prolonged delay, reassess schedule |
| Environmental excursion | Adjust controls, document | If prolonged, assess product impact |

### 9.2 Rejection Criteria

Material shall be rejected if:
- Visible mold or fungal growth
- Evidence of active pest infestation
- Foreign matter contamination
- Cannot verify identity/traceability
- QA directs rejection

Rejected material shall be:
- Segregated and labeled "REJECTED"
- Documented with reason
- Disposed per waste procedures
- Excluded from batch yield

## 10. TRACEABILITY

### 10.1 Batch Identification

Harvest Batch Number format: <span class="var">[HARV-YYYYMMDD-CCC-###]</span>

| Component | Meaning |
|-----------|---------|
| HARV | Harvest identifier |
| YYYYMMDD | Harvest date |
| CCC | Cultivar code (3 letters) |
| ### | Sequential batch number |

**Example:** <span class="var">[HARV-20250122-OGK-001]</span>

### 10.2 Traceability Chain

```
Mother Plant ID → Clone Batch → Veg Batch → Flower Batch → Harvest Batch → Drying Batch → Final Product
```

All links documented in batch records and reconciled at each stage.
