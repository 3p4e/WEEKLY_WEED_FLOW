## 1. Purpose

This Standard Operating Procedure establishes controlled procedures for the primary packaging of cannabis products to ensure product protection, maintain quality throughout shelf life, comply with regulatory labeling requirements, and ensure full batch traceability. Primary packaging is defined as the packaging in direct contact with the product.

---

## 2. Scope

This SOP applies to:

- **Dried cannabis flower** packaging
- **Cannabis extracts** (oils, concentrates) packaging
- **Pre-rolled products** packaging
- **All primary packaging materials** in contact with product
- **All personnel** involved in packaging operations
- **Primary labeling** operations

## 6. Pre-Packaging Requirements

### 6.1 Line Clearance

**Before any packaging operation, verify:**

| Check | Verification | Initial |
|-------|-------------|---------|
| **Previous batch removed** | No product, labels, or materials from prior batch | |
| **Equipment clean** | Per cleaning log, visual verification | |
| **Area clean** | Floor, surfaces, equipment | |
| **Correct packaging materials** | Part numbers match batch record | |
| **Correct labels** | Content verified against master | |
| **Equipment calibrated** | Scales, checkweighers current | |
| **Environmental conditions** | Temp/RH within specification | |

Document on **Line Clearance Form (FM-PRO-040)**.

### 6.2 Material Verification

**For each packaging material:**

1. **Verify** part number matches batch record specification
2. **Check** lot number and expiration date
3. **Inspect** for damage or contamination
4. **Confirm** QC release status
5. **Record** quantities issued to line

### 6.3 Label Verification

**Critical label checks before use:**

| Element | Verification Method |
|---------|-------------------|
| **Product name** | Match to batch record |
| **Batch number** | Correct and legible |
| **Cannabinoid content** | Match CoA values |
| **Net weight/volume** | Match fill specification |
| **Expiration date** | Correctly calculated |
| **Regulatory warnings** | Present and complete |
| **Track-and-trace code** | Unique, scannable |

**First Article Inspection:**
- Print <span class="var">[3]</span> labels before production
- QC approval required before line start
- Attach approved sample to batch record

## 7. Packaging Procedure - Cannabis Flower

### 7.1 Setup

1. **Complete** line clearance (Section 6.1)
2. **Stage** packaging materials at workstation
3. **Verify** scale calibration with check weights
4. **Set up** nitrogen flush system (if used)
5. **Configure** label printer with correct template
6. **Print** and verify first article labels

### 7.2 Filling Operation

**Step 1: Container Preparation**

1. Inspect container for defects (cracks, chips, contamination)
2. Reject any defective containers
3. Place container on work surface or filling station

**Step 2: Product Filling**

1. **Tare** scale with empty container (if weighing in container)
2. **Dispense** product to target weight
3. **Verify** weight is within specification:
   - Target: <span class="var">[Per product specification]</span>
   - Range: <span class="var">[±5%]</span>
4. **Adjust** if necessary
5. **Record** weight (for statistical sampling)

**Step 3: Humidity Control (if applicable)**

1. Add humidity pack of appropriate size
2. Position to avoid direct contact with product surface

**Step 4: Nitrogen Flush (if applicable)**

1. Insert nitrogen wand into container
2. Flush for <span class="var">[2-3 seconds]</span> at <span class="var">[2-3 L/min]</span>
3. Remove wand while continuing flush
4. Immediately apply closure

**Step 5: Closure Application**

1. Apply closure with appropriate torque
2. Target torque: <span class="var">[8-12 inch-lbs]</span> for standard CRC
3. Engage child-resistant feature
4. Verify closure is properly seated

**Step 6: Tamper-Evident Seal**

1. Apply induction seal (if applicable)
2. Or apply shrink band/wrap
3. Verify seal integrity

### 7.3 Labeling Operation

**Step 1: Label Application**

1. Apply primary label to designated position
2. Ensure label is straight and bubble-free
3. Verify all printed information is legible

**Step 2: Secondary Labels (if applicable)**

1. Apply warning labels as required
2. Apply track-and-trace label
3. Verify barcode scannability

### 7.4 In-Process Checks

| Check | Frequency | Specification | Record |
|-------|-----------|--------------|--------|
| **Weight** | <span class="var">[Every unit or statistical sampling]</span> | Within ±5% | In-process log |
| **Closure Torque** | <span class="var">[Start, every 30 min, end]</span> | <span class="var">[8-12 inch-lbs]</span> | In-process log |
| **Label Accuracy** | <span class="var">[Every 15 min]</span> | All elements correct | In-process log |
| **Seal Integrity** | <span class="var">[Every 15 min]</span> | Complete, no defects | In-process log |
| **Visual Inspection** | <span class="var">[Every unit]</span> | No defects | Visual |

### 7.5 Statistical Weight Control

For batches > <span class="var">[100 units]</span>, implement statistical sampling:

| Batch Size | Sample Size | Frequency |
|------------|-------------|-----------|
| <span class="var">[100-500]</span> | <span class="var">[20 units]</span> | Start, middle, end |
| <span class="var">[500-1000]</span> | <span class="var">[30 units]</span> | Every 100 units |
| <span class="var">[>1000]</span> | <span class="var">[50 units]</span> | Per control plan |

**Acceptance Criteria:**
- Average weight ≥ target
- No individual weight < <span class="var">[95%]</span> of target
- Standard deviation within control limits

## 8. Packaging Procedure - Cannabis Oils

### 8.1 Setup

1. Complete line clearance
2. Set up volumetric filler or dispensing system
3. Verify dispense accuracy with test runs
4. Purge system with nitrogen (if applicable)

### 8.2 Filling Operation

**Step 1: Container Preparation**

1. Inspect bottles for defects
2. Pre-flush with nitrogen (if required)

**Step 2: Product Filling**

1. **Dispense** to target volume
2. **Verify** fill level visually or by weight
3. **Weight verification**: Target ±3%

**Step 3: Closure and Dropper Assembly**

1. Apply dropper/pipette insert
2. Secure outer cap with appropriate torque
3. Verify child-resistant function

**Step 4: Labeling**

1. Apply labels per specification
2. Include dosing instructions
3. Verify cannabinoid content on label matches CoA

## 11. Rejection and Rework

### 11.1 Rejection Criteria

| Defect Category | Examples | Action |
|-----------------|----------|--------|
| **Critical** | Wrong product, missing labels, contamination | Reject, investigate |
| **Major** | Incorrect weight, illegible label, damaged seal | Reject or rework |
| **Minor** | Cosmetic defects, slight label misalignment | Case-by-case |

### 11.2 Rework Procedure

**Rework is permitted only for:**
- Label replacement (if product integrity maintained)
- Repackaging of undamaged product
- QA approval required for all rework

**Rework Process:**

1. Document rework authorization on Rework Form (FM-PRO-043)
2. Segregate material for rework
3. Perform rework under supervision
4. Re-inspect 100% of reworked units
5. Document completion and QA approval

### 11.3 Reconciliation

At batch completion, reconcile:

| Material | Calculation |
|----------|-------------|
| **Product** | Input − (Packaged + Samples + Rejects + Retained) = Yield |
| **Containers** | Issued − (Used + Damaged + Returned) = Accounted |
| **Labels** | Issued − (Used + Damaged + Returned) = Accounted |
| **Closures** | Issued − (Used + Damaged + Returned) = Accounted |

**Acceptable Yield**: <span class="var">[≥98%]</span> (investigate below this)
**Label Reconciliation**: <span class="var">[100%]</span> accounted (critical)

## 13. Equipment Cleaning

### 13.1 Between Batches (Same Product)

1. Remove residual product
2. Wipe surfaces with approved cleaner
3. Visual inspection
4. Document on batch record

### 13.2 Between Products (Changeover)
