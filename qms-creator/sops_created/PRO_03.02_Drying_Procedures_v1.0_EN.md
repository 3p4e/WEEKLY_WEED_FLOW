## 1. PURPOSE

### 1.1 Objective

This Standard Operating Procedure establishes the requirements and procedures for the controlled drying of harvested cannabis at <span class="var">[COMPANY_NAME]</span> to ensure:

- Consistent product quality and cannabinoid preservation
- Achievement of target moisture content for stability
- Prevention of microbial growth during drying
- Preservation of terpene profile
- Compliance with EU GMP and GACP requirements

### 1.2 Background

Proper drying is critical to medical cannabis quality. The drying process must:
- Reduce moisture content from <span class="var">[75-80%]</span> (fresh) to <span class="var">[8-12%]</span> (dried)
- Occur slowly enough to preserve terpenes and prevent chlorophyll breakdown
- Be fast enough to prevent mold and bacterial growth
- Maintain controlled environmental conditions throughout

## 4. DEFINITIONS

| Term | Definition |
|------|------------|
| **Drying** | Controlled process of reducing moisture content in harvested cannabis through air circulation and environmental control |
| **Moisture Content** | Percentage of water in plant material by weight, determined by loss on drying |
| **Water Activity (aw)** | Measure of available water in product; critical for microbial stability |
| **Relative Humidity (RH)** | Percentage of water vapor in air relative to saturation at given temperature |
| **Whole Plant Drying** | Drying entire plant or branches with flowers attached |
| **Rack Drying** | Drying of flowers/branches on mesh racks |
| **Hang Drying** | Drying of branches suspended from lines |
| **Air Exchange Rate** | Number of complete air changes per hour in drying room |
| **Equilibrium Moisture** | Stable moisture content achieved when drying rate equals rehydration rate |

## 5. SAFETY PRECAUTIONS

### 5.1 Personal Protective Equipment (PPE)

| Activity | Required PPE |
|----------|-------------|
| Entering drying room | Clean room gown, hair cover, shoe covers, gloves |
| Handling wet material | Nitrile gloves, waterproof apron |
| HVAC maintenance | Per maintenance SOP |

### 5.2 Safety Hazards

| Hazard | Precaution |
|--------|-----------|
| Slippery floors (moisture) | Non-slip footwear, wet floor signs |
| Ergonomic (repetitive motion) | Job rotation, proper lifting technique |
| Allergens (plant material) | PPE, personnel screening |
| Fire risk (dried material) | No ignition sources, fire extinguisher access |

### 5.3 Emergency Procedures

- In case of fire: Evacuate immediately, activate alarm, use fire extinguisher only if safe
- In case of HVAC failure: Notify Maintenance immediately, open manual vents if available
- In case of power failure: Backup generator should activate; if not, follow emergency procedures

| Parameter | Impact if Out of Range |
|-----------|----------------------|

| Temperature <15°C | Slowed drying, increased mold risk |

## 9. IN-PROCESS CONTROLS

### 9.1 Critical In-Process Controls

| Control Point | Parameter | Specification | Frequency | Response if OOS |
|--------------|-----------|---------------|-----------|-----------------|
| Room Temperature | T | <span class="var">[15-22°C]</span> | Continuous | Adjust HVAC, investigate |
| Room Humidity | RH | <span class="var">[55-65%]</span> | Continuous | Adjust dehumidifier, investigate |
| Moisture Content | LOD | Trending toward <span class="var">[8-12%]</span> | Daily (from Day 7) | Continue drying |
| Visual Quality | Appearance | No mold, even drying | Daily | Isolate affected, investigate |

### 9.2 Alert and Action Responses

**Temperature Alert (<span class="var">[±2°C]</span> from setpoint):**
1. Verify HVAC operation
2. Check for door left open, equipment malfunction
3. Document observation
4. If not resolved in <span class="var">[1 hour]</span>, escalate

**Temperature Action (<span class="var">[±3°C]</span> from setpoint):**
1. Immediately notify Supervisor
2. Initiate deviation report
3. Assess impact on material
4. Take corrective action
5. QA notification

**Humidity Alert (<span class="var">[±5%]</span> from setpoint):**
1. Check dehumidifier operation
2. Check for water leaks, wet cleaning
3. Document observation
4. Adjust equipment if needed

**Humidity Action (<span class="var">[±10%]</span> from setpoint):**
1. Immediately notify Supervisor
2. Initiate deviation report
3. If RH >70%, check material for mold
4. Take corrective action
5. QA notification

### 9.3 Mold Detection Response

If mold is detected during visual inspection:

| Step | Action |
|------|--------|
| 1 | STOP all activity in drying room |
| 2 | Do not disturb affected material |
| 3 | Notify Supervisor and QA immediately |
| 4 | Quarantine affected material |
| 5 | Sample for laboratory confirmation |
| 6 | Assess potential spread to adjacent material |
| 7 | Initiate deviation report |
| 8 | QA determines disposition |

**Note:** Moldy material must NEVER be processed or released.

## 10. TROUBLESHOOTING

### 10.1 Common Issues and Solutions

| Issue | Possible Cause | Solution |
|-------|----------------|----------|
| Drying too slow | RH too high | Lower RH setpoint, check dehumidifier |
| | Poor air circulation | Adjust fans, reduce loading density |
| | Loading density too high | Redistribute material |
| | HVAC issue | Contact Maintenance |
| Drying too fast | RH too low | Raise RH setpoint |
| | Temperature too high | Lower temperature setpoint |
| | Air velocity too high | Reduce fan speed |
| Uneven drying | Poor loading | Redistribute material |
| | Air circulation blocked | Remove obstructions, adjust fans |
| | Sensor placement issue | Verify sensor position |
| Mold development | RH too high | Immediate action per 9.3 |
| | Dead spots (no air flow) | Improve circulation, remove affected |
| | Contaminated equipment | Deep clean, investigate source |
| Off-odors | Anaerobic conditions | Improve circulation |
| | Material quality issue | Investigate source batch |

### 10.2 Emergency Procedures

**Power Failure:**
1. Backup generator should activate within <span class="var">[30 seconds]</span>
2. If backup fails, open emergency vents
3. Monitor room conditions manually
4. Notify Maintenance immediately
5. Document outage duration and conditions

**HVAC Failure:**
1. Notify Maintenance immediately
2. Open manual vents if available
3. Bring in portable dehumidifiers/fans
4. Monitor conditions closely
5. Assess material impact
