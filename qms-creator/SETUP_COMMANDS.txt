Ollama VPS Setup - Copy & Paste Commands
==========================================

Step 1: Connect to VPS
----------------------
ssh root@72.61.176.37
# Password: C2nnabis123qwe123


Step 2: Update System (Run on VPS)
----------------------------------
apt-get update && apt-get upgrade -y

apt-get install -y curl wget git ufw docker.io docker-compose


Step 3: Install Ollama (Run on VPS)
-----------------------------------
curl -fsSL https://ollama.ai/install.sh | sh

cat > /etc/systemd/system/ollama.service << 'EOF'
[Unit]
Description=Ollama AI Model Server
After=network-online.target
Wants=network-online.target

[Service]
Type=notify
ExecStart=/usr/local/bin/ollama serve
User=root
Restart=always
RestartSec=3
Environment="OLLAMA_HOST=0.0.0.0:11434"
Environment="OLLAMA_ORIGINS=*"

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable ollama
systemctl start ollama
sleep 5


Step 4: Configure Firewall (Run on VPS)
---------------------------------------
ufw --force reset
ufw default deny incoming
ufw default allow outgoing
ufw allow 22/tcp
ufw allow 11434/tcp
ufw allow 80/tcp
ufw allow 443/tcp
echo 'y' | ufw enable


Step 5: Install Models (Run on VPS - Takes Time)
------------------------------------------------
ollama pull llama3.2
ollama pull codellama
ollama pull deepseek-coder
ollama pull qwen2.5-coder

ollama list


Step 6: Test Installation (Run on VPS)
--------------------------------------
curl -s http://localhost:11434/api/version
curl -X POST http://localhost:11434/api/generate -H "Content-Type: application/json" -d '{"model":"llama3.2","prompt":"Say hello!","stream":false}'

SSH Key Setup (Run on LOCAL Machine)
==========================================

# Or manually add this to /root/.ssh/authorized_keys on VPS:
cat ~/.ssh/hostinger-vps-access.pub


==========================================
Add to ~/.ssh/config (Run on LOCAL Machine)
==========================================

cat >> ~/.ssh/config << 'EOF'

# Hostinger VPS - Ollama Server
Host ollama-vps
    HostName srv1211306.hstgr.cloud
    User root
    Port 22
    IdentityFile ~/.ssh/hostinger-vps-access
    ForwardAgent yes
EOF
