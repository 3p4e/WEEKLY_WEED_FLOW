**Parent SOP:** QA_00.02_A03_v1 Document Control
**Annex Code:** QA_00.02_A03_v1
**Version:** 1.0
**Effective Date:** 2026-01-22

---

## PURPOSE

This annex provides the standardized form for requesting changes to existing controlled documents within the Quality Management System.

---

## INSTRUCTIONS FOR COMPLETION

1. Complete all sections of this form clearly and legibly (use black ink for paper forms)
2. Attach supporting documentation (deviation reports, audit findings, regulatory updates, etc.)
3. Submit completed form to Quality Assurance Manager for evaluation
4. Minor changes (typos, formatting, clarifications) can be processed directly under QA_00.02_A03_v1
5. Major changes (procedure changes, scope expansion, new requirements) require formal Change Control per QAS-00-005

## FORM USAGE NOTES

### When to Use This Form:

**YES - Use This Form:**
- Requesting revision to existing controlled document
- Periodic review indicates changes needed
- Implementing CAPA or deviation corrective action
- Addressing audit finding
- Updating for regulatory change
- Process improvement requiring SOP update

**NO - Do Not Use This Form:**
- Creating NEW document (use document creation process per QA_00.02_A03_v1 Section 5.2)
- Reporting deviation (use Deviation Report form per QAS-00-007)
- Initiating CAPA (use CAPA Initiation form per QAS-00-006)
- Emergency temporary procedure (contact QA Manager directly)

### Form Submission:

**Submit completed form to:**
- Quality Assurance Manager
- Email: [QUALITY_ASSURANCE_MANAGER_EMAIL]
- Physical location: QA Office, Document Control

**Response Time:**
- Minor changes: Evaluation within 5 working days
- Major changes: Evaluation within 10 working days
- Critical safety/regulatory: Evaluation within 24 hours

### Electronic Submission:

If using electronic document management system:
- Complete form electronically (fillable PDF or web form)
- Electronic signature acceptable if system validated per EU Annex 11
- Auto-routing to QA Manager
- Tracking number auto-assigned
