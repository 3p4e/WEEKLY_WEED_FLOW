# ANNEX A04: OBSOLETE DOCUMENT HANDLING PROCEDURE

**Parent SOP:** QA_00.02_A04_v1 Document Control
**Annex Code:** QA_00.02_A04_v1
**Version:** 1.0
**Effective Date:** 2026-01-22

---

## PURPOSE

This annex establishes the procedures for identifying, retrieving, marking, archiving, and disposing of obsolete documents to prevent unintended use while maintaining required records per EU GMP requirements (Chapter 4, Sections 4.10-4.12).

---

## SCOPE

This procedure applies to all controlled documents that have been superseded by new versions or are no longer required for operational use.

---

## 1. DEFINITION OF OBSOLETE DOCUMENTS

### 1.1 A Document Becomes Obsolete When:

**Superseded by New Version:**
- A new version of the document has been approved and effective date reached
- Original document no longer valid for operational use
- Example: SOP v1.0 superseded by SOP v2.0

**Withdrawn from Use:**
- Document no longer required (procedure discontinued, equipment decommissioned, etc.)
- Formally withdrawn by Change Control process
- Example: SOP for equipment no longer in use

**Expiry of Temporary/Interim Documents:**
- Interim SOP reaches expiry date (maximum 90 days)
- Temporary protocol completes its intended use
- Example: Validation protocol completed and report issued

---

## 2. OBSOLETE DOCUMENT IDENTIFICATION

### 2.1 Automatic Identification

**When New Version Becomes Effective:**
- QA Manager identifies all superseded versions automatically
- Document Control Register updated with "OBSOLETE" status
- Effective date of new version = obsolescence date of old version

**Example:**
- Old version: QA_00.02_A04_v1 v1.0 (Effective until 31-Jan-2026)
- New version: QA_00.02_A04_v1 v2.0 (Effective 01-Feb-2026)
- v1.0 becomes obsolete on 01-Feb-2026

### 2.2 Planned Withdrawal

**For Documents Being Withdrawn (not superseded):**
- Document owner submits Document Withdrawal Request to QA Manager
- Includes reason for withdrawal and impact assessment
- Quality Manager approves withdrawal
- Withdrawal date assigned (typically 30 days notice)

## 3. RETRIEVAL OF OBSOLETE DOCUMENTS

### 3.1 Notification of Document Obsolescence

**Within 24 hours of new version effective date, QA Manager shall:**

1. **Send Notification to All Controlled Copy Holders:**
   - Email notification (template below)
   - Physical memo for non-email personnel
   - Post notice on document control board

**Email Notification Template:**

```
Subject: DOCUMENT OBSOLETE - [Document Code] [Document Title]

To: [Controlled Copy Holders]

Effective Date: [DD-MMM-YYYY]

This is to notify you that the following document is now OBSOLETE:

Document Code: [Code]
Document Title: [Title]
Obsolete Version: [Old Version]
Superseded By: [New Document Code] v[New Version]

ACTION REQUIRED:
1. Remove obsolete version from point of use IMMEDIATELY
2. Return obsolete controlled copy to QA within 5 working days
3. Sign acknowledgment of receipt of new version (if applicable)
4. Destroy any uncontrolled copies made from obsolete version

Contact QA Manager for replacement controlled copy of new version.

Failure to return obsolete documents is a GMP deviation and will be documented.

[QUALITY_ASSURANCE_MANAGER]
Quality Assurance Manager
[Contact Information]
```

### 3.2 Retrieval Process

**Controlled Copy Holders Shall:**

**Within 5 Working Days:**
1. Remove obsolete document from all points of use
2. Mark "OBSOLETE - RETURNED TO QA" on cover page
3. Return to QA Manager (deliver to QA Office or internal mail)
4. Sign Document Return Log confirming return
5. Receive new version (if applicable)

**QA Manager Shall:**
1. Check returned documents against distribution list
2. Verify all controlled copies accounted for
3. Follow up on unreturned copies (email reminder at Day 3, escalation to Department Manager at Day 6)
4. Document retrieval status in Document Control Register

### 3.3 Unreturned Controlled Copies

**If controlled copy not returned within 10 working days:**

1. **QA Manager Escalates to Department Manager:**
   - Email escalation with copy to Quality Manager
   - Request immediate return or explanation

2. **If Still Not Returned (Day 15):**
   - Raise Deviation Report (Deviation from Document Control procedure)
   - Investigate why copy not returned
   - Assess risk (is obsolete document still in use?)
   - Implement CAPA to prevent recurrence

3. **Emergency Situation (if obsolete doc found in use):**
   - Immediate stop use notification
   - Product/batch impact assessment
   - Investigation per QAS-00-007 Deviation Management
   - Potential batch quarantine if critical procedure violated

## 4. MARKING OBSOLETE DOCUMENTS

### 4.1 Paper-Based Documents

**All Obsolete Documents Shall Be Marked as Follows:**

**Method 1: Stamp (Preferred)**
- Apply "OBSOLETE - DO NOT USE" stamp in RED INK
- Stamp diagonally across EACH PAGE (minimum 3 stamps per page: top-right, center, bottom-left)
- Stamp size: Minimum 10 cm × 3 cm for visibility

**Method 2: Manual Marking (if stamp unavailable)**
- Write "OBSOLETE - DO NOT USE" in RED INK across each page
- Marker pen or red pen acceptable
- Large, bold letters across page diagonal
- Initial and date each page

**Additional Information on Cover Page:**
- "SUPERSEDED BY: [New Document Code] v[New Version]"
- "OBSOLETE DATE: [DD-MMM-YYYY]"
- "ARCHIVED BY: [Name] DATE: [DD-MMM-YYYY]"

**Example Marking:**

```
        OBSOLETE - DO NOT USE

SUPERSEDED BY: QA_00.02_A04_v1 v2.0
OBSOLETE DATE: 01-FEB-2026
ARCHIVED BY: [QA Manager Name]
DATE: 01-FEB-2026
```

### 4.2 Electronic Documents

**For Electronic Document Management Systems:**

**Version Control System Shall:**
1. Automatically move obsolete version to "Archive" folder
2. Apply electronic watermark: "OBSOLETE - DO NOT USE" (RED, diagonal)
3. Change file status to "SUPERSEDED" or "OBSOLETE"
4. Restrict access (read-only for authorized personnel, no access for general users)
5. Display prominent banner when opened: "WARNING: This is an obsolete document"

**Manual Electronic Document Marking (if no automated system):**
1. Move file to Archive folder structure
2. Rename file: [Original Name]_OBSOLETE_[Date]
3. Add metadata: Status = Obsolete, Superseded By = [New Version]
4. Restrict folder permissions (QA Manager and Quality Manager only)

## 5. ARCHIVING OBSOLETE DOCUMENTS

### 5.1 Archiving Requirements (per EU GMP 4.10-4.12)

**What to Archive:**
- **ONE Master Copy of Each Obsolete Document**
  - The original approved copy with original signatures (or validated electronic equivalent)
  - All annexes and associated forms
  - Revision history and change documentation

**What to Destroy:**
- All other controlled copies (after marking)
- All uncontrolled copies (if returned)
- Draft versions and working copies

### 5.2 Archive Organization

**Physical Archive Structure:**

```
Archive Room / Cabinet / Shelf
  └── By Document Type
      └── By Document Code
          └── By Year of Obsolescence
              └── Individual Document Folders

Example:
Archive Cabinet 1 / Shelf 2 / SOPs / QA_00.02_A04_v1 / 2026 / v1.0 (OBSOLETE 01-FEB-2026)
```

**Archive Storage Requirements:**
- **Location:** Secure, access-controlled archive area (separate from active document storage)
- **Environment:** Climate-controlled (15-25°C, 40-60% RH), protected from light, moisture, pests
- **Security:** Locked cabinets or rooms, access restricted to QA Manager and designated personnel
- **Fire Protection:** Fire suppression system or fire-resistant cabinets for critical documents
- **Organization:** Clearly labeled, easy retrieval, indexed

**Electronic Archive Structure:**

```
Archive Drive / Folder Structure:
  ├── QAS_Quality_Assurance_System
  │   ├── QAS-00-002_Document_Control
  │   │   ├── v1.0_OBSOLETE_2026-02-01
  │   │   │   ├── QAS-00-002_v1.0_Main_SOP.pdf
  │   │   │   ├── QAS-00-002_A01_v1.0_Annex.pdf
  │   │   │   └── Approval_Records.pdf
  │   │   └── v2.0_CURRENT
  │   └── [Other QAS SOPs]
  └── [Other Chapters]
```

**Backup Requirements:**
- Electronic archives backed up weekly (minimum)
- Off-site backup or cloud backup for disaster recovery
- Backup verification quarterly
- Retention period applies to backups as well

**QA Manager Maintains Archive Register Containing:**

**Archive Register Requirements:**
- Updated within 48 hours of archiving document
- Reviewed quarterly for accuracy
- Used to track retention expiry and disposal

## 6. RETENTION PERIODS (per EU GMP 4.11-4.12)

### 6.1 Document-Specific Retention Periods

**Batch-Related Documentation:**
- **Retention:** 1 year after product expiry OR 5 years after QP certification, **WHICHEVER IS LONGER**
- **Examples:**
  - Batch Production Records
  - Batch Packaging Records
  - Batch QC test results
  - Certificates of Analysis
- **Notes:** For cannabis, product expiry typically 12-24 months, so 5-year minimum applies

**Investigational Medicinal Products:**
- **Retention:** 5 years after clinical trial completion or formal discontinuation
- **Examples:** IMP batch records, specific IMPs documentation
- **Notes:** Only if Purely Plant conducts clinical trials

**Validation and Stability Data:**
- **Retention:** **Lifetime of Marketing Authorization** (indefinite) OR until superseded by full new dataset
- **Examples:**
  - Validation protocols and reports (process, cleaning, method, equipment)
  - Stability study protocols and data
  - Qualification records (IQ, OQ, PQ)
- **Supersession:** If full revalidation performed, old data may be retired after 5 years, with documented justification

**Quality Management System Documents (SOPs, Specifications):**
- **Retention:** **Lifetime of current version + 5 years after superseded**
- **Examples:**
  - Obsolete SOPs
  - Superseded specifications
  - Old forms and templates
- **Rationale:** May be needed to investigate historical batches or deviations

**Training Records:**
- **Retention:** Duration of employment + 5 years
- **Examples:** Individual training records, competency assessments
- **Notes:** Covers personnel who may have worked on batches still within retention

**Deviation, CAPA, Audit Records:**
- **Retention:** **10 years minimum**
- **Examples:**
  - Deviation investigation reports
  - CAPA records
  - Internal audit reports
  - External audit responses
- **Rationale:** Long-term trend analysis, regulatory inspection evidence

**Equipment Records:**
- **Retention:** Lifetime of equipment + 2 years after decommissioning
- **Examples:**
  - Equipment logbooks
  - Maintenance records
  - Calibration certificates
- **Notes:** Needed to support batch records produced on that equipment

**Change Control Records:**
- **Retention:** 10 years minimum
- **Examples:** Change control records, impact assessments, approvals
- **Rationale:** Historical documentation of QMS evolution

### 6.2 Retention Period Calculation

**Start Date:** Date document becomes obsolete (superseded date or withdrawal date)

**End Date:** Start date + retention period

**Example 1:**
- Document: Batch Record for Batch 2025-001
- Product Expiry: 31-DEC-2026
- QP Certification: 15-JAN-2025
- Retention calculation:
  - Option 1: 1 year after expiry = 31-DEC-2027
  - Option 2: 5 years after certification = 15-JAN-2030
  - **Retention until: 15-JAN-2030** (whichever is longer)

**Example 2:**
- Document: QA_00.02_A04_v1 Document Control SOP v1.0
- Obsolete Date: 01-FEB-2026
- Document Type: SOP (Retention = current version life + 5 years)
- **Retention until: 01-FEB-2031**

## 7. RETRIEVAL OF ARCHIVED DOCUMENTS

### 7.1 Permitted Retrieval Purposes

Archived obsolete documents may be retrieved ONLY for:
- Investigation of historical batches or deviations
- Regulatory inspection or audit
- Litigation or legal requirements
- Internal audit or quality review
- Historical research for process improvement

### 7.2 Retrieval Process

**Request Procedure:**
1. **Requester Completes Archive Retrieval Request Form:**
   - Document Code and version needed
   - Reason for retrieval
   - Requester name and department
   - Date range of batches/events being investigated (if applicable)

2. **QA Manager Reviews Request:**
   - Verifies valid business reason
   - Approves or denies request
   - If approved, retrieves document from archive

3. **Document Loan:**
   - Archived document provided as **UNCONTROLLED COPY ONLY**
   - Original archived master remains in archive
   - Copy clearly marked "ARCHIVED DOCUMENT - FOR REFERENCE ONLY - DO NOT USE FOR OPERATIONS"
   - Requester signs Archive Loan Log

4. **Return:**
   - Document returned or copy destroyed after use
   - Return documented in Archive Loan Log
   - Maximum loan period: 30 days (extension requires Quality Manager approval)

### 7.3 Archive Loan Log

| Loan ID | Archived Doc Code | Version | Requester | Department | Reason | Date Out | Date Returned | Approved By |

## 8. DISPOSAL OF ARCHIVED DOCUMENTS

### 8.1 Disposal Eligibility

**Documents Eligible for Disposal When:**
- Retention period has expired (per Section 6)
- No ongoing investigations, audits, or legal matters requiring the document
- Quality Manager approves disposal

**Annual Review Process:**
1. **QA Manager Reviews Archive Register (January each year):**
   - Identifies documents with retention expiry in previous year
   - Generates list of documents eligible for disposal

2. **Quality Manager Reviews List:**
   - Verifies no ongoing needs for documents
   - Approves disposal or extends retention (with justification)

3. **Disposal Executed:**
   - Per Section 8.2 below

### 8.2 Disposal Methods

**Paper Documents:**
- **Method:** Confidential shredding or incineration
- **Witnessed:** QA Manager + 1 witness (QA Officer or Quality Manager)
- **Documentation:** Disposal documented in Document Destruction Log

**Electronic Documents:**
- **Method:** Secure electronic deletion (non-recoverable)
  - Overwrite file with random data (minimum 3 passes)
  - OR use certified data destruction software
  - OR physically destroy storage media (hard drive shredding)
- **Witnessed:** IT Administrator + QA Manager
- **Documentation:** Electronic Disposal Log

**Document Destruction Log:**

| Destruction ID | Document Code | Version | Title | Obsolete Date | Retention Expiry | Destruction Date | Destruction Method | Witness 1 | Witness 2 |
|----------------|---------------|---------|-------|---------------|------------------|--------------------|-------------------|-----------|-----------|

**Signatures Required:**
- Witness 1 (QA Manager): _________________ Date: _________
- Witness 2: _________________ Date: _________

### 8.3 Disposal Documentation Retention

**Destruction Logs Retained:**
- Minimum 5 years after destruction
- Provides audit trail of document lifecycle
- Evidence of GMP compliance with retention requirements

## 9. SPECIAL CIRCUMSTANCES

### 9.1 Obsolete Documents Found in Use

**If obsolete document discovered being used operationally:**

**IMMEDIATE ACTIONS:**
1. **STOP USE IMMEDIATELY**
2. Notify QA Manager and Quality Manager immediately
3. Quarantine affected product/batch (if applicable)
4. Initiate Deviation Report (QAS-00-007)
5. Conduct impact assessment:
   - Was correct procedure followed despite wrong document version?
   - Did obsolete version have different requirements?
   - Is product quality affected?
   - Is patient safety affected?

**INVESTIGATION:**
- Root cause analysis: Why was obsolete doc in use? (e.g., not returned, new version not distributed, training gap)
- Extent: Check other areas for same issue
- CAPA: Prevent recurrence

**POTENTIAL CONSEQUENCES:**
- Product rejection or rework
- Batch rejection
- Retraining
- Process improvements

### 9.2 Regulatory Inspection Request for Archived Documents

**If inspector requests archived document:**
1. QA Manager retrieves from archive
2. Provides copy marked "ARCHIVED DOCUMENT - SUPERSEDED VERSION"
3. Explains current version and changes made
4. Provides current version as well for comparison
5. Documents inspection request in Archive Retrieval Log

### 9.3 Litigation Hold

**If legal proceedings require retention beyond normal period:**
1. Legal department notifies Quality Manager
2. Quality Manager issues "Litigation Hold" notice
3. Affected documents flagged in Archive Register: "HOLD - DO NOT DESTROY"
4. Documents retained until legal matter resolved and hold released
5. Disposal proceeds after hold release (if retention period expired)

### 9.4 Lost or Destroyed Archived Documents

**If archived document lost or accidentally destroyed:**
1. **Immediate Notification:** QA Manager notifies Quality Manager and QP
2. **Investigation:** Deviation report initiated
3. **Reconstruction Attempts:**
   - Search for duplicate copies (controlled copies, electronic backups)
   - Contact original author/approvers for copies
   - Check off-site backup archives
4. **Documentation:** Document loss in Archive Register
5. **Impact Assessment:** Assess regulatory and business impact
6. **CAPA:** Prevent recurrence (improve archive security, backup procedures)
7. **Regulatory Notification:** If regulatory requirement to retain, notify authority per local regulations

## 10. TRAINING

**Personnel Requiring Training on This Procedure:**
- QA Manager (comprehensive training)
- QA Officers (comprehensive training)
- All Departmental Managers (overview training)
- All personnel who create or use controlled documents (awareness training)

**Training Frequency:**
- Initial: During GMP induction
- Refresher: Every 24 months
- Upon significant procedure changes

**Training Content:**
- Recognizing obsolete documents
- Returning obsolete documents promptly
- Never using obsolete documents operationally
- Retrieval process for archived documents
- Retention requirements

## 11. METRICS AND MONITORING

**Monthly Metrics (QA Manager Reports):**
- Number of documents obsoleted
- Percentage of controlled copies retrieved within 5 days (target: 100%)
- Number of unreturned controlled copies (target: 0)
- Number of overdue archived documents for disposal

**Quarterly Audit:**
- Random archive inspection (verify documents properly marked and stored)
- Archive Register accuracy check
- Retention period compliance review

**Annual Review:**
- Full archive inventory
- Disposal eligibility review
- Archive space and organization assessment
- Retention policy review for continued appropriateness
