## FORM USAGE NOTES

### When to Use This Form:

**YES - Use Change Control Request:**
- Any change to facilities, equipment, processes, materials, or critical documentation
- New equipment installation or existing equipment modification
- Process parameter changes
- Supplier or material changes
- Organizational changes (key personnel)
- Changes to validated systems
- Facility modifications

**NO - Use Document Change Request Instead (QAS-00-002 Annex A03):**
- Minor SOP revisions (typos, clarifications, formatting)
- Document review cycles
- Administrative documentation updates

### Form Submission:

**Submit completed form to:**
- Quality Assurance Manager
- Email: [QUALITY_ASSURANCE_MANAGER_EMAIL]
- Physical location: QA Office

**Response Time:**
- Routine changes: CCN assigned within 2 working days
- Urgent changes: CCN assigned within 1 working day
- Emergency changes: Immediate (contact QA Manager and Quality Manager by phone)

### Tips for Completing Form:

1. **Be Specific:** Vague descriptions delay approval. State exactly what will change.
2. **Provide Context:** Explain why change is needed - regulatory, quality improvement, equipment failure, etc.
3. **Identify All Impacts:** Consider products, processes, documentation, training, validation.
4. **Attach Supporting Docs:** Vendor specs, regulatory guidance, deviation reports, etc.
5. **Estimate Realistically:** Implementation timeline, resources, costs.
6. **Ask Questions:** Contact QA Manager if unsure how to complete any section.
