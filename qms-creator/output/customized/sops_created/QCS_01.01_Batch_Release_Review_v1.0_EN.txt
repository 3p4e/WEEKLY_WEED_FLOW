## Преглед за ослободување на серија | Batch Release Review

### 1. PURPOSE / ЦЕЛ

This procedure defines the process for reviewing batch documentation prior to QC release approval.
Целта на оваа процедура е да ја дефинира процедурата за преглед на документацијата пред одобрување на QC.

### 2. SCOPE / ОПСЕГ

Applies to all batch release reviews at Purely Plant GmbH.

### 3. PROCEDURE / ПРОЦЕДУРА

1. Review batch documentation
2. Verify QC test results
3. Confirm compliance with specifications
4. Approve or reject batch for release
